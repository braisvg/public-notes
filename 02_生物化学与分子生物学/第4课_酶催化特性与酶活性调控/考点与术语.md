## 第一部分：考点清单（老师原话 + 重点预测）

### 一、老师当堂强调的考点（保留原话）

> 【考点】"考试必考，要求不看教材就能写出来"——**米氏方程：V = Vmax[S]/(Km+[S])**

> 【考点】"Km 是酶的特征性常数/特异性常数，与酶浓度无关，只与酶空间结构、底物有关；同一种酶催化不同底物 Km 不同"

> 【考点】"Km 反映酶与底物的亲和力——反比：Km 大亲和力小，Km 小亲和力强"

> 【考点】"Km 定义 = 反应速率达 1/2 Vmax 时的底物浓度，单位 mol/L"

> 【考点】"最适温度不是特征常数，Km 才是"

> 【考点】"立体结构特异性可归入绝对特异性"

> 【考点】"酶原激活教材定义不全——辅助因子（金属离子）的参与加入也是酶原激活的一部分"

> 【考点】"关键酶 = 活性决定某一代谢途径速率和方向的一个或几个酶"

> 【考点】"磷酸化修饰是生命信号传导的最关键信号"

> 【考点】"维生素与微量元素是自学内容，但很可能期末考试会有一两个题目"

> 【考点】"中间产物学说/诱导契合学说——有可能考"（诱导契合：酶与底物相互诱导、相互变形、相互适应）

> 【考点】"三种可逆抑制剂的特点和作用比较，回家想一想：三种抑制剂分别加入后，继续增大底物浓度会有什么影响"（思考题，考试高频变体）

### 二、考试重点预测（按出现频率排序）

1. **米氏方程默写 + Km 定义 + Km 与亲和力关系**（最核心）
2. **三类可逆抑制剂的动力学特征对比**（Vmax/Km 变化，双倒数作图判断）
3. **不可逆抑制剂实例**：有机磷→胆碱酯酶（解磷定）、砷化物→巯基酶（二巯基丙醇）
4. **酶促反应三大特点**：高效性（10⁸~10²⁰倍）、特异性（绝对/相对/立体）、可调节性
5. **酶原激活**：机理（肽键断裂+辅助因子加入）、胰蛋白酶原、生理意义 3 点（保护/定位/主动）
6. **关键酶/限速酶**：定义 + 磷酸果糖激酶（糖酵解）
7. **共价修饰**：磷酸化氨基酸 = Ser/Thr/Tyr；磷酸化失调→癌症
8. **同工酶**：定义 + LDH + 临床意义（器官特异、辅助诊断）
9. **快速调节 vs 慢速调节**：构象调节（酶原激活/变构/共价修饰）vs 酶含量调节
10. **维生素分类**：水溶性/脂溶性；维生素=辅助因子的一种
11. **酶降解调控**：泛素化标记→溶酶体/蛋白酶体降解→信号回传再合成
12. **复习提问**：核糖体（原核70S/真核80S）、tRNA 三叶草+倒L、mRNA 帽+polyA、生命时钟=端粒

### 三、老师口误/笔记错误纠正说明（重要）

| 笔记原文 | 正确内容 | 说明 |
|----------|----------|------|
| 胱氨酸、氨酸、脂肪酸 | **丝氨酸（Ser）、苏氨酸（Thr）、酪氨酸（Tyr）** | 可被磷酸化的三种氨基酸（含羟基） |
| 肌红蛋白 | 肌动蛋白（actin） | 手指运动是肌动蛋白+肌球蛋白磷酸化 |
| 解定磷 | 解磷定（碘解磷定，PAM） | 有机磷中毒解毒药 |
| 原琥珀酸 | 延胡索酸（fumarate） | 琥珀酸脱氢酶产物（笔记"原琥珀酸产生减少"实为"延胡索酸"） |
| 胂化合物/砷化物 | 砷剂（砒霜成分为三氧化二砷） | 巯基酶抑制剂，用二巯基丙醇解毒 |
| 0105蛋白酶 | 蛋白酶（胃蛋白酶类） | 语音识别误差 |
| 变过/变购 | 变构（allosteric） | 变构调节/变构剂 |
| 泛数字化修饰 | 泛素化修饰（ubiquitination） | 蛋白降解标记 |
| 酶的潜景 | 酶原的潜伏（潜态） | 活性中心被隐藏的状态 |
| 反应跟新抑制剂 | 反竞争性抑制剂（uncompetitive inhibitor） | 只与ES结合 |
| 米曼式方程 | 米氏方程（Michaelis-Menten） | 动力学方程 |
| 双倒数作图 | Lineweaver-Burk 作图 | 1/V 对 1/[S] 作图 |

## 第二部分：中英对照术语表

### 一、核心动力学概念

| 中文 | 英文 | 说明 |
|------|------|------|
| 米氏方程 | Michaelis–Menten equation | V = Vmax[S]/(Km+[S])，必考 |
| 最大反应速率 | maximum velocity (Vmax) | 酶被底物饱和时的极限速率 |
| 米氏常数 | Michaelis constant (Km) | 1/2 Vmax 时的底物浓度，特征常数 |
| 亲和力 | affinity | 酶与底物结合能力，与 Km 成反比 |
| 双倒数作图 | Lineweaver–Burk plot | 1/V 对 1/[S] 直线作图 |
| 一级反应 | first-order reaction | V 与 [S] 成正比阶段 |
| 零级反应 | zero-order reaction | 达 Vmax 后 V 与 [S] 无关 |
| 中间产物 | intermediate (ES complex) | 酶-底物复合物 |
| 诱导契合 | induced-fit | 酶与底物相互适应结合 |

### 二、抑制剂与激活剂

| 中文 | 英文 | 说明 |
|------|------|------|
| 抑制剂 | inhibitor | 降低酶活性的物质 |
| 不可逆抑制剂 | irreversible inhibitor | 共价结合，透析/超滤不可去除 |
| 可逆抑制剂 | reversible inhibitor | 非共价结合，可透析去除 |
| 竞争性抑制剂 | competitive inhibitor | Vmax不变、Km增大；如丙二酸、甲氨蝶呤 |
| 非竞争性抑制剂 | non-competitive inhibitor | Km不变、Vmax减小 |
| 反竞争性抑制剂 | uncompetitive inhibitor | Km、Vmax均减小；只与ES结合 |
| 琥珀酸脱氢酶 | succinate dehydrogenase | 三羧酸循环酶，被丙二酸竞争抑制 |
| 丙二酸 | malonate | 琥珀酸结构类似物 |
| 甲氨蝶呤 | methotrexate (MTX) | 二氢叶酸还原酶竞争性抑制剂（抗癌药） |
| 二氢叶酸还原酶 | dihydrofolate reductase | 四氢叶酸合成的关键酶 |
| 有机磷化合物 | organophosphate | 胆碱酯酶不可逆抑制剂（农药/神经毒剂） |
| 胆碱酯酶 | cholinesterase | 水解乙酰胆碱；被有机磷磷酸化失活 |
| 解磷定 | pralidoxime (PAM) | 有机磷中毒解毒药 |
| 砷化物 | arsenicals | 巯基酶不可逆抑制剂 |
| 二巯基丙醇 | dimercaprol (BAL) | 砷中毒解毒药 |
| 激活剂 | activator | 增强酶活性的物质 |
| 必需激活剂 | essential activator | 多为金属离子，缺失则酶无活性 |
| 非必需激活剂 | non-essential activator | 提高活性，缺失仍可催化 |

### 三、酶活性调节

| 中文 | 英文 | 说明 |
|------|------|------|
| 关键酶/限速酶 | key enzyme / rate-limiting enzyme | 决定代谢途径速率与方向 |
| 磷酸果糖激酶 | phosphofructokinase (PFK) | 糖酵解限速酶 |
| 变构调节 | allosteric regulation | 代谢物结合活性中心外部位改变酶构象 |
| 变构激活剂 | allosteric activator | 增强酶与底物结合 |
| 变构抑制剂 | allosteric inhibitor | 降低酶活性 |
| 共价修饰 | covalent modification | 磷酸化/甲基化/乙酰化等 |
| 磷酸化 | phosphorylation | 最重要信号；Ser/Thr/Tyr |
| 丝氨酸 | serine (Ser) | 可被磷酸化 |
| 苏氨酸 | threonine (Thr) | 可被磷酸化 |
| 酪氨酸 | tyrosine (Tyr) | 可被磷酸化 |
| 酶原 | zymogen / proenzyme | 无活性前体 |
| 酶原激活 | zymogen activation | 肽段切除+辅助因子加入→活性中心形成 |
| 胰蛋白酶原 | trypsinogen | →胰蛋白酶（经典例子） |
| 急性胰腺炎 | acute pancreatitis | 酶原异常激活致病例 |
| 凝血因子 | coagulation factor | 按需激活（酶原激活意义） |
| 泛素化 | ubiquitination | 标记衰老蛋白→降解 |
| 溶酶体 | lysosome | 蛋白降解场所之一 |
| 蛋白酶体 | proteasome | 泛素-蛋白酶体途径降解 |

### 四、其他

| 中文 | 英文 | 说明 |
|------|------|------|
| 同工酶 | isoenzyme / isozyme | 催化相同反应、结构不同的酶 |
| 乳酸脱氢酶 | lactate dehydrogenase (LDH) | 同工酶典型，LDH1~5 |
| 维生素 | vitamin | 辅助因子的一种；水溶性/脂溶性 |
| 水溶性维生素 | water-soluble vitamin | B族、C |
| 脂溶性维生素 | fat-soluble vitamin | A、D、E、K |
| 微量元素 | trace element | 多为酶的必需激活剂/金属辅基 |
| 活化能 | activation energy | 酶降低活化能加速反应 |
| 绝对特异性 | absolute specificity | 只催化一种底物一种反应（脲酶） |
| 相对特异性 | relative specificity | 作用于一类化合物/一种化学键（磷酸酶） |
| 立体结构特异性 | stereospecificity | 只作用于特定立体构型（D/L） |
| 高效性 | high efficiency | 提高速率10⁸~10²⁰倍 |

| 酸碱催化 | acid-base catalysis | 活性中心酸碱基团供受质子 |
| 表面效应 | surface effect | 水化膜影响底物接近 |
| 端粒 | telomere | 生命时钟，随年龄变短 |
| 核糖体 | ribosome | 蛋白质合成场所（原核70S/真核80S） |
