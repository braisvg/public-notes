# 毛概第2课：考点与术语

> 本文件汇总 2026-09-14 毛概第2课（毛泽东思想及其历史地位·导论）的**老师强调考点**（尽量保留原话）、时间线记忆点与术语对照。

## 一、老师课堂强调的重点（原话摘录）

1. **"上节课我也说了，马克思主义中国化是什么呀？就是马克思主义到达中国，我们要将它进行一个本土化，那这本土化产生的第一个成果，第一个历史性的被认识，就是毛泽东思想，这个大家一定要记住"** ——毛泽东思想=马克思主义中国化第一次历史性飞跃，必记。
2. **"大家要记住的关键节点就是……1945年，只要提到时间节点，大家一定要想时间节点"** ——时间节点意识：1935遵义、1945七大、1949建国。
3. **"遵义会议就是一次具有伟大转折意义的重要会议……它主要是在危急关头挽救了党，还有挽救了红军和中国革命"** ——遵义会议地位。
4. **"不要死守在原地啊，你要随时跟着实际情况去调整，这个就是要看他的视野"** ——实事求是精神的体现。
5. **"那大家可能觉得这个伟人，他是不是这一路走来顺风顺水啊……他经历的多，他才能看得远"** ——毛泽东思想源于革命实践。
6. **"新民主主义……这一理论体系，它精准全面地反映了中国新民主主义革命的客观规律，形成了完备，而且系统的理论框架，成为了毛泽东思想走向成熟的标志"** ——新民主主义革命理论地位。

## 二、高频考点清单

### 概念类
1. **历史周期率**：其兴也勃焉、其亡也忽焉的王朝兴亡循环；毛泽东第一答案=**让人民监督政府（民主）**；习近平第二答案=**党的自我革命**。
2. **毛泽东思想定义**（四要素）：马列主义在中国的运用和发展；关于中国革命和建设的正确的理论原则和经验总结；集体智慧的结晶；第一次历史性飞跃。
3. **新民主主义革命总路线**：无产阶级领导、工农联盟、反帝反封建反官僚资本主义、前途社会主义。
4. **活的灵魂**：实事求是、群众路线、独立自主。
5. **"中国特色社会主义理论体系"不包括毛泽东思想**（选择题高频）。

### 时间线类（必背）
| 时间 | 考点 |
|------|------|
| 1900/1901 | 八国联军侵华/《辛丑条约》——进入20世纪的中国 |
| 1917 | 十月革命；李大钊《庶民的胜利》《布尔什维主义的胜利》"赤旗的世界" |
| 1925 | 五卅运动；《中国社会各阶级的分析》 |
| 1927 | 大革命失败（四一二/七一五）；秋收起义→上井冈山；《湖南农民运动考察报告》 |
| 1928~1930 | 《中国的红色政权为什么能够存在？》《井冈山的斗争》《星星之火，可以燎原》《反对本本主义》"没有调查，没有发言权" |
| 1935.1 | 遵义会议——伟大转折，挽救党/红军/中国革命 |
| 1937 | 《实践论》《矛盾论》 |
| 1945 | 七大确立毛泽东思想为指导思想（成熟标志） |
| 1949.4 | 占领南京，《七律·人民解放军占领南京》"百万雄师过大江" |
| 1956+ | 《论十大关系》《关于正确处理人民内部矛盾的问题》"第二次结合" |

### 分析类
6. **毛泽东思想形成4阶段**：萌芽（大革命时期）→初步形成（土地革命时期）→成熟（1935~1945）→继续发展（1945~1976）。
7. **为什么不能照搬俄国城市起义**：统治力量在城市集中强大、无合法斗争空间、革命主力军在农村。
8. **主要内容6方面**：新民主主义革命理论/社会主义革命和建设理论/革命军队建设和军事战略/政策和策略/思想政治工作和文化工作/党的建设。
9. **民族资产阶级两面性**：革命性+妥协性，既联合又斗争；官僚资产阶级是革命对象。
10. **"共同富裕"最早由毛泽东提出雏形**。

## 三、易错点与辨析

| 易混点 | 辨析 |
|--------|------|
| 第一个答案 vs 第二个答案 | 毛泽东：让人民监督政府（民主）；习近平：党的自我革命 |
| 初步形成 vs 成熟标志 | 初步形成=农村包围城市道路（井冈山时期）；成熟标志=七大确立指导思想（1945） |
| 《反对本本主义》 vs 《实践论》 | 前者1930（初步形成期，提出没有调查没有发言权）；后者1937（成熟期哲学基础） |
| 新民主主义革命 vs 社会主义革命 | 前者反帝反封建反官僚资本、前途社会主义；后者消灭剥削制度、确立社会主义制度 |
| 民族资产阶级 vs 官僚资产阶级 | 前者两面性可争取；后者是革命对象 |
| 毛泽东思想 vs 中国特色社会主义理论体系 | 前者是飞跃①；后者是改革开放后的理论成果，**不包括**毛泽东思想 |
