# 生理学第4课：考点与术语

> 本文件汇总 2026-09-14 生理学第4课的**老师强调考点**（尽量保留原话）、备考策略与中英对照术语。

---

## 一、老师课堂强调的重点（原话摘录）

> 以下为录音转写中老师明说"重点"或反复强调的内容，已纠正转写错别字：

1. **"细胞兴奋后兴奋性的变化，这个我们也是一个重点的内容，你要注意把它掌握了"** ——绝对不应期/相对不应期，且生理学实验课会测神经干AP绝对不应期（刺激伪迹、第二个AP消失）。
2. **"这个是我们第三节，这个细胞电活动的内容重点就在这里了"** ——动作电位机制（Na⁺内流/K⁺外流、电压门控钠钾通道）是收尾重点。
3. **"影响骨骼肌收缩效能的因素……是一个重点内容，前负荷后负荷肌肉的收缩能力。还有呢，收缩总和"** ——四大因素必背。
4. **"多单位的运动总和要注意的就是它有什么呀？大小原则，收缩的时候是先小后大；舒张的时候呢，反过来先大后小"** ——运动单位大小原则。
5. **"骨骼肌和心肌呢都属于横纹肌，那我们这里呢，重点呢要去看的就是横纹肌的情况"** ——横纹肌范围界定。
6. 老师用思维导图方式总结全课：**神经肌肉接头处的兴奋传递（电-化学-电过程）→ 兴奋-收缩耦联（三联管，Ca²⁺）→ 收缩蛋白的横桥周期**，以及四大影响因素。

## 二、高频考点清单（按出现顺序）

### 动作电位部分
1. **刺激三要素**：强度（波高）、持续时间（波宽）、强度-时间变化率（斜率）——方波刺激图。
2. **阈强度/阈刺激/阈上刺激/阈下刺激**概念区分。
3. **阈电位定义** + **比静息电位小10~20mV**（-70→-55mV）。
4. **影响阈电位的因素**：钠通道密度功能、细胞外Ca²⁺（高钙上移、低钙下移→低钙手足搐搦）、局麻药（普鲁卡因抑制钠通道）。
5. **AP传播**：无髓顺序式连续传导（局部电流）、有髓跳跃式（郎飞结，提速+节能）、缝隙连接（同步化活动，如心肌）。
6. **电压门控钠通道三状态**：静息（m关h开）、激活（m开h开）、失活（m开h关）；失活→复活。
7. **绝对不应期**（兴奋性0，=锋电位，钠通道激活或失活）+ **相对不应期**（复极化晚期+后超极化，阈上刺激可兴奋）。
8. **AP三特点**：全或无、不衰减传播、脉冲式发放。
9. **兴奋性**：可兴奋细胞=神经/肌/腺细胞；兴奋标志=产生AP；兴奋性高低用阈值衡量（反比）。
10. **电紧张电位**：被动电学特性（Rm、Ri、Cm）；空间常数λ（1/e≈37%，髓鞘/直径影响）；时间常数τ（63%/37%，Rm、Cm影响）；**有髓纤维传导快=λ大τ小**。
11. **电紧张电位极性**：负电极下去极化、正电极下超极化；负电极下才生AP。
12. **局部电位**：定义（部分通道开放、不能远传）；三种（终板电位、发生器电位、突触后电位）；**与AP四对比**（等级性/衰减性/无不应期可总和/可发生于不产AP的细胞）。

### 肌细胞收缩部分
13. **神经-肌肉接头三结构**：接头前膜/接头间隙/接头后膜（终板膜）；N₂受体+胆碱酯酶。
14. **传递7步**（电-化学-电）：AP→前膜去极→钙通道开放Ca²⁺内流→囊泡出胞释放ACh→ACh结合N₂受体→Na⁺内流K⁺外流→EPP→电紧张扩布→肌膜AP→胆碱酯酶分解ACh。
15. **量子式释放**：1量子=1囊泡；一次AP约释放125个囊泡、激活约2×10⁵个通道；mEPP约0.4mV；**冯德培**（Ca²⁺依赖性+强直后增强PTP）。
16. **影响传递因素**：肉毒杆菌毒素（抑释放）、α-银环蛇毒/箭毒碱/重症肌无力（堵受体）、有机磷（抑胆碱酯酶）、新斯的明（抑AChE改善肌无力）。
17. **肌节**：Z线-Z线=收缩舒张基本单位；A带/I带/H带/M线/Z线；**收缩时A带不变、I带和H带变窄**。
18. **肌管系统**：横管传AP、纵管（肌质网）贮/放Ca²⁺；LSR回收Ca²⁺、JSR（终池）释放Ca²⁺（RyR）；三联管（骨骼肌）/二联管（心肌）。
19. **粗肌丝**=肌球蛋白（横桥：ATP酶活性+结合肌动蛋白，扭动45°，每次拖动5~15nm）；**细肌丝**=肌动蛋白7:原肌球蛋白1:肌钙蛋白1（7:1:1）；**肌钙蛋白**：TnC结合Ca²⁺（4个）、TnT结合原肌球蛋白、TnI结合肌动蛋白。
20. **横桥周期4步**：结合→发力（释放ADP+Pi，扭动）→解离（ATP结合）→复位（ATP分解）；耗能；Ca²⁺↑启动、Ca²⁺↓停止。
21. **兴奋-收缩耦联**：概念（中介过程）、结构基础（三联管）、耦联因子（Ca²⁺）；4步过程（T管传AP→SR释钙→Ca²⁺触发收缩→SR回收钙）。
22. **骨骼肌vs心肌**：骨骼肌L型钙通道变构（拔塞样）+RyR1；心肌Ca²⁺内流钙触发钙释放（CICR）+RyR2；三联管/二联管。
23. **等长收缩**（长度不变张力增）vs**等张收缩**（长度缩短张力不变）。
24. **前负荷（preload）**：收缩前负荷=初长度；**最适初长度（肌节2.0~2.2μm）产生最大张力**；长度-张力曲线（总张力=主动+被动）。
25. **后负荷（afterload）**：先等长后等张；后负荷↑→张力↑、缩短迟/小/慢；过大→纯等长；张力-速度曲线（负荷0→Vmax；负荷P₀→速度0）。
26. **肌肉收缩能力（contractility）**：与负荷无关的内在特性（Ca²⁺、横桥ATP酶活性、能量代谢、肌纤维结构）。
27. **收缩总和**：多纤维总和（大小原则：收缩先小后大、舒张先大后小）+频率总和（单收缩/不完全强直/完全强直）；**生理情况下几乎全是完全强直收缩**。

## 三、易错点与辨析

| 易混概念 | 区别要点 |
|---------|---------|
| 阈强度 vs 阈电位 | 阈强度是**刺激**的最小强度；阈电位是**膜电位**的临界值 |
| 电紧张电位 vs 局部电位 | 前者被动特性（无通道激活）；后者主动特性（部分通道激活） |
| 局部电位 vs 动作电位 | 等级性/衰减/可总和 vs 全或无/不衰减/有不应期 |
| 绝对不应期 vs 相对不应期 | 兴奋性0、钠通道激活或失活 vs 兴奋性渐恢复、钠通道逐渐复活 |
| 横管 vs 纵管 | 横管传AP（电）；纵管（SR）贮放回收Ca²⁺（钙） |
| 三联管 vs 二联管 | 骨骼肌 vs 心肌（T管与单侧终池） |
| 等长 vs 等张 | 长度不变张力增 vs 长度缩短张力不变 |
| 前负荷 vs 后负荷 | 收缩前负荷（初长度） vs 收缩后负荷 |
| 主动张力 vs 被动张力 | 肌丝滑行产生 vs 弹性成分（结缔组织）产生 |
| 单收缩/不完全/完全强直 | 刺激频率递增，收缩融合程度递增；完全强直波形平滑无锯齿 |
| 骨骼肌L型钙通道 vs 心肌 | 变构（电压传感器） vs 少量Ca²⁺内流触发（CICR） |

## 五、备考策略

1. **本课=上一节（第3课）的"下半场"**：先复习第3课的静息/动作电位机制，再学触发-传播-不应期-局部电位，逻辑是连贯的。
2. **必背数值清单**：阈电位-55mV（比静息小10~20mV）、AP超射+30mV、mEPP 0.4mV、量子125个囊泡/2×10⁵通道、λ 0.1~3mm、τ 1~20ms、肌节最适长度2.0~2.2μm、横桥每次拖动5~15nm、7:1:1比例。
3. **必背图表**：①动作电位模式图（ab/bc/cd/de各段机制）；②钠通道三状态图；③不应期与AP时间关系图；④局部电位与AP对比表；⑤神经-肌接头传递7步图；⑥三联管结构图；⑦横桥周期4步图；⑧长度-张力曲线；⑨张力-速度曲线；⑩频率总和三种收缩曲线。
4. **临床联系常考**：低钙手足搐搦、局麻药、肉毒杆菌毒素、银环蛇毒、重症肌无力、有机磷中毒、箭毒碱肌松——每个都要能说出作用环节。
5. **与后续章节衔接**：缝隙连接同步化（心肌收缩）、EPP与突触传递（第十章）、钙触发钙释放（心肌生理）——本课是基础。
6. **复习顺序建议**：先看知识点总结.md（已插入课堂照片+批注），再对着考点清单自查，最后用思维导图（见科目根目录）复述逻辑链。
