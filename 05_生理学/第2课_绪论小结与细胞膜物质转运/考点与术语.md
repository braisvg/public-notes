# 生理学第2课 考点与术语

## 高频考点预测

1. **细胞膜结构**：液态镶嵌模型，脂质双层+镶嵌蛋白，厚度7~8nm
2. **单纯扩散转运物质**：O₂、CO₂、N₂、类固醇激素、乙醇、尿素、水（少量）
3. **经通道易化扩散特点**：离子选择性、门控特性（电压/化学/机械门控），速率极快
4. **经载体易化扩散三特点**：结构特异性、饱和现象、竞争性抑制
5. **钠泵工作过程**：3Na⁺出胞、2K⁺入胞、分解1ATP，E1↔E2构象循环
6. **钠泵生理意义**（5条）：维持胞内高K⁺、维持渗透压/细胞容积、生物电基础、继发性主动转运势能储备、生电效应
7. **钠泵的临床联系**：强心苷类（地高辛）抑制钠泵→治疗心衰，但可致心律失常
8. **钙泵**：PMCA和SERCA，维持胞质游离Ca²⁺在0.1~0.2μmol/L
9. **质子泵**：胃壁细胞H⁺,K⁺-ATP酶，奥美拉唑（PPI）抑制→治胃溃疡
10. **被动转运vs主动转运**：方向、能量、膜蛋白需求对比

## 专业术语表

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| 细胞膜 | cell membrane (plasma membrane) | 分隔细胞质与细胞周围环境的膜结构，厚7~8nm |
| 液态镶嵌模型 | fluid mosaic model | 脂质双层为骨架，蛋白质镶嵌其中的膜结构模型 |
| 磷脂 | phospholipid | 膜脂质主要成分，占70%以上 |
| 胆固醇 | cholesterol | 膜脂质成分，不超过30% |
| 糖脂 | glycolipid | 膜脂质成分，不超过10% |
| 两亲性分子 | amphiphilic molecule | 同时具有亲水性和疏水性的分子（如磷脂） |
| 脂质双层 | lipid bilayer | 两层脂质分子亲水端朝外、疏水端相对排列 |
| 膜蛋白 | membrane protein | 细胞膜功能的主要执行者 |
| 表面膜蛋白 | peripheral membrane protein | 附着于膜表面，占20%~30% |
| 整合膜蛋白 | integral membrane protein | 贯穿脂质双层，占70%~80%（通道、载体、泵、受体） |
| 糖蛋白 | glycoprotein | 糖类与膜蛋白结合形成，分布于膜外表面 |
| 跨膜物质转运 | transmembrane transport | 物质通过细胞膜的过程 |
| 被动转运 | passive transport | 顺浓度梯度，不耗能 |
| 单纯扩散 | simple diffusion | 脂溶性物质直接穿过脂质双层 |
| 易化扩散 | facilitated diffusion | 非脂溶性物质在膜蛋白帮助下顺浓度梯度转运 |
| 经通道易化扩散 | facilitated diffusion via channel | 离子经通道蛋白顺电化学梯度跨膜 |
| 经载体易化扩散 | facilitated diffusion via carrier | 小分子物质经载体蛋白顺浓度梯度跨膜 |
| 离子通道 | ion channel | 贯穿膜的亲水性孔道，介导离子快速转运 |
| 离子选择性 | ion selectivity | 通道只对特定离子有较高通透性 |
| 门控特性 | gating | 通道蛋白闸门受刺激后开放或关闭的特性 |
| 电压门控通道 | voltage-gated ion channel | 受膜电位变化控制的通道 |
| 化学门控通道 | chemically-gated ion channel | 受化学物质（配体）控制的通道 |
| 机械门控通道 | mechanically-gated ion channel | 受机械刺激控制的通道 |
| 非门控通道 | non-gated channel | 始终开放的通道（如钾漏通道） |
| 钾漏通道 | potassium leak channel | 非门控K⁺通道，静息电位基础 |
| 载体（转运体） | carrier (transporter) | 介导小分子跨膜的整合膜蛋白 |
| 结构特异性 | structural specificity | 载体只结合特定化学结构的底物 |
| 饱和现象 | saturation | 底物浓度过高时载体转运速率达Vmax不再增加 |
| 竞争性抑制 | competitive inhibition | 结构相似底物竞争同一载体结合位点 |
| 最大转运速率 | Vmax | 载体全部饱和时的转运速率 |
| 米氏常数 | Km | 转运速率达Vmax一半时的底物浓度 |
| 葡萄糖转运体 | GLUT (glucose transporter) | 介导葡萄糖经载体易化扩散的蛋白家族 |
| 主动转运 | active transport | 逆浓度梯度，耗能的跨膜转运 |
| 原发性主动转运 | primary active transport | 直接分解ATP供能的主动转运 |
| 继发性主动转运 | secondary active transport | 利用Na⁺/H⁺浓度梯度势能的主动转运 |
| 钠-钾泵（钠泵） | sodium-potassium pump (Na⁺-K⁺ pump) | Na⁺,K⁺-ATP酶，3Na⁺出/2K⁺入 |
| 生电效应 | electrogenic effect | 钠泵每次循环净出1个正电荷 |
| 钙泵 | calcium pump (Ca²⁺-ATPase) | 将胞质Ca²⁺转运至胞外或肌质网 |
| 质膜钙ATP酶 | PMCA | 分布于细胞膜上的钙泵 |
| 肌质网钙ATP酶 | SERCA | 分布于肌质网/内质网膜的钙泵 |
| 质子泵 | proton pump (H⁺,K⁺-ATPase) | 胃壁细胞分泌H⁺的离子泵 |
| 哇巴因 | ouabain | 钠泵特异性抑制剂 |
| 强心苷 | cardiac glycoside | 抑制钠泵的强心药物（地高辛、洋地黄） |
| 奥美拉唑 | omeprazole | 质子泵抑制剂（PPI），治胃溃疡 |
