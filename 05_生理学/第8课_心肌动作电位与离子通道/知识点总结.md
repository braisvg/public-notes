## 第一章 上节回顾与深入讲解（重点补全）

### 1.1 心动周期七期与心音——用"压力差"一条主线串起来

上节课我们把心动周期拆成了七个时期。这节课老师开场用一个统一原理重新串了一遍，**这个原理就是"压力差"**：

> **血液从压力高处往压力低处流；瓣膜只向压力低的一侧开放。** 几乎所有时期，血流方向和瓣膜开关都由压力差决定——唯一例外是**减慢射血期**：此时室内压已略低于主动脉压，但血液仍靠前两期积累的**流动惯性**继续往外流。

老师把七期按"压力差→瓣膜→血流"的逻辑过了一遍：

1. **等容收缩期**：心室开始收缩 → 室内压急剧升高 → 一旦超过房压，**房室瓣关闭（S₁，标志收缩开始）**；此时仍低于主动脉压，动脉瓣仍关 → 两瓣均关，容积不变，压力快速上升。
2. **快速射血期**：心室继续强力收缩 → 室内压超过主动脉压 → **动脉瓣开放** → 血液快速射入主动脉；此期末室内压和主动脉压都达到整个心动周期最高峰。
3. **减慢射血期**：心室收缩减弱，室内压从顶峰下降，**甚至略低于主动脉压**，但血液靠惯性继续外流；期末心室容积最小。
4. **等容舒张期**：心室开始舒张 → 室内压急剧下降 → 一旦低于主动脉压，**动脉瓣关闭（S₂，标志舒张开始）**；此时仍高于房压，房室瓣仍关 → 两瓣均关，容积不变，压力快速下降。
5. **快速充盈期**：心室继续主动舒张 → 室内压低于房压（甚至负压）→ **房室瓣开放** → 血液被"抽吸"快速冲入心室；此期充盈量占总充盈2/3；期末室内压最低。
6. **减慢充盈期**：心室主动舒张已近极限，压力差变小，血液缓慢流入；此期最长（约0.22 s）但量少（约8%）。
7. **心房收缩期**：心室已不能再舒张，此时还差最后约1/4的充盈量，靠心房主动收缩把这部分血挤入心室；期末心室容积最大（=舒张末期容积EDV）。

【考点】S₁ = 房室瓣关闭 = 心室收缩开始；S₂ = 动脉瓣关闭 = 心室舒张开始。老师原话："通过听诊两个'勒-哒'之间的间隔，短的是收缩期、长的是舒张期，正常人一听就知道舒张期更长。"

### 1.2 瓣膜病：关闭不全 vs 狭窄（老师课堂听了心音笔记）

老师在课堂上放了正常心音和二尖瓣病变的心音笔记，要求同学理解两个概念：

- **瓣膜关闭不全（regurgitation）**：门没关严。以二尖瓣关闭不全为例——心室收缩时本该把血全部射入主动脉，但二尖瓣没关严，一部分血从左心室**反流回左心房**。听诊上，整个收缩期都能听到这种反流的"吹风样"杂音，而不是清脆的S₁。
- **瓣膜狭窄（stenosis）**：门太小。心室舒张时血要从心房穿过狭窄的房室瓣流入心室，血流加速产生湍流，也会出现舒张期杂音。

老师强调：心脏瓣膜一生要开放关闭约30亿次（75岁×75次/分），本身就是易损结构；年龄衰老、风湿免疫、酗酒等都会加速瓣膜病。

### 1.3 五个心功能指标——对比表（必背）

上节课我们只讲了心动周期"过程"，这节课回答一个新问题：**怎么定量评价心脏泵血得多还是少？** 老师一口气讲了五个指标，这五个指标名字像、容易混，但临床意义完全不同。

| 指标 | 英文缩写 | 定义 | 公式 | 正常值（安静、成人） | 临床意义与易错点 |
|---|---|---|---|---|---|
| **每搏输出量**（搏出量） | SV | 一侧心室一次心搏射出的血量 | SV = EDV − ESV | **60~80 mL**（约70 mL） | 单次指标；单独看SV**早期心衰时可正常**，会漏诊 |
| **射血分数** | EF | SV占心室舒张末期容积的百分比 | EF = SV / EDV × 100% | **55%~65%** | 比SV更敏感；**心脏扩大但SV正常时EF已下降**，是早期心衰指标；心脏彩超常规测量 |
| **心输出量** | CO | 一侧心室每分钟射出的血量 | CO = SV × HR | **4.5~6.0 L/min**（约5 L/min） | 连续指标；运动时可增至25~35 L/min；象征"每分钟把全身血量（占体重4~8%）循环一遍" |
| **心指数** | CI | 空腹安静时每平方米体表面积的CO | CI = CO / 体表面积 | **3.0~3.5 L/(min·m²)** | 剔除身材差异，用于不同个体间比较；体表面积由身高体重估算 |
| **心力储备** | cardiac reserve | CO随机体代谢需要而增加的能力 | 最大CO − 安静CO | 健康成人为安静值的**6~7倍**（可达25~35 L/min） | 分**搏出量储备**（收缩期储备>舒张期储备）+**心率储备**；运动员储备大，心衰患者储备小 |

【考点·老师原话】

- "**SV约70 mL，但单看SV往往看不出问题**——扩张型心肌病心脏已经变大了，但SV还维持在70 mL；因为它的EDV也变大了（比如140 mL），70/140=50%，EF已经掉到正常下限以下。所以**EF比SV更敏感**。"
- "**CO不是一氧化碳**，是心输出量（cardiac output）。SV×HR=CO，安静时70 mL×75次≈5 L。这个知识点年年考，SV和CO名字像，经常有人混。"
- "血液约占体重4~8%，按50 kg体重算约4 L；安静时CO≈5 L，意味着**每分钟把全身血液泵一遍**——这是CO的象征意义。"
- "心功能差的人安静时CO也能维持5 L，但那是因为他**安静时已经在动用储备**了（比如心率偏快），一旦运动就无法再提升——所以心衰患者'安静没事、不能干活'。"

### 1.4 心力储备（老师特别强调收缩期储备更大）

老师原话："**搏出量储备分收缩期储备和舒张期储备，其中收缩期储备更大。**"

- **收缩期储备**：安静时ESV约55 mL；剧烈收缩时ESV可降到20 mL以下 → 多射出约35 mL。这是真正的"大空间"。
- **舒张期储备**：安静时EDV约125 mL；舒张更充分时EDV可到140 mL → 仅多容纳约15 mL。老师强调"这15 mL其实也很难真正达到，受心包、心室结构限制"。
- **心率储备**：安静75次/分 → 最大可到160~180次/分（但超过180后充盈不足，CO反而下降）。

### 1.5 影响心输出量的三因素（重点）

CO = SV × HR，所以影响CO的因素分两大类：影响SV的（前负荷、后负荷、心肌收缩能力）+ 影响HR的。

#### （1）前负荷——异长自身调节（Frank-Starling定律）

- **前负荷 = 心肌收缩前的初长度 = 心室舒张末期容积（EDV）**。直接测心室容积困难，临床常用**左房压（或肺动脉楔压）**代表前负荷。
- **Frank-Starling定律**：在一定范围内，回心血量越多（EDV越大），心室收缩力越强、搏出量越多——这是心肌的**自身调节**，不依赖神经体液。
- **心室功能曲线（Frank-Starling曲线）**：横坐标=左房压（代表前负荷），纵坐标=搏出功。与骨骼肌长度-张力曲线不同，**心肌的曲线上升后变平、没有明显下降支**。
- **为什么心肌曲线不降？结构基础**：①心肌细胞内有**肌联蛋白（titin）**这种强弹性蛋白，像弹簧一样把肌节拉住，过度拉长很难；②心肌外间质有**胶原纤维**提供弹性阻力；③心肌纤维是**交错网状排列**（不像骨骼肌平行排列），不容易被拉散。
- **生理意义**：心脏在安静状态下**远未达到最适初长度**（老师说最适长度对应左房压约15 mmHg，而安静时仅约5 mmHg），所以有很大前负荷储备。回心血量短暂增加（体位改变、输液）→ EDV增加 → 搏出量自动增加，保持左右心输出量平衡。

【考点】**异长自身调节（heterometric autoregulation）= 通过改变心肌初长度（前负荷）调节搏出量**；与之相对的是**等长调节**（见下）。

**影响前负荷（静脉回心血量）的5个因素**：
1. **心室充盈时间**：心率过快→舒张期短→充盈不足→前负荷↓；
2. **静脉回流速度**：取决于外周静脉压与房压差；心室舒张抽吸越强、压差越大、回流越快；
3. **心室舒张功能**：舒张是主动耗能过程，依赖肌质网**钙泵（SERCA）**把Ca²⁺泵回——钙回收越快、舒张越快、抽吸越强；
4. **心室顺应性**：心室被动扩张的容易程度；心肌纤维化→顺应性↓→充盈困难；
5. **心包**：心包积液/缩窄→限制心室扩张→前负荷↓。

#### （2）后负荷——动脉血压

- **后负荷 = 心室收缩射血时遇到的阻力 = 主动脉血压**。
- 血压突然升高 → 等容收缩期延长（要更长时间才能把室内压升到超过主动脉压）→ 射血期缩短、射血速度减慢 → 搏出量暂时↓ → 心室内剩余血量↑ → 下一轮EDV↑ → 通过异长自身调节搏出量恢复。
- **80~170 mmHg范围内**，这种代偿可以维持搏出量稳定；但长期高血压 → 心肌做功持续增加 → **心肌肥厚**（向心性肥厚）→ 肥厚心肌挤占心室腔容积 + 心肌耗氧增加而冠脉供血相对不足 → 最终心功能下降、搏出量↓。
- 心电图上的"左室高电压"就是左室心肌肥厚的表现。
- 降压药（如ACEI/ARB类）通过扩张动脉降低外周阻力，从而降低后负荷。

#### （3）心肌收缩能力——等长调节

- **定义**：不依赖前/后负荷，心肌本身收缩效能的改变。
- **机制**：①活化横桥数目（胞质Ca²⁺浓度越高、维持越久，活化横桥越多）；②肌钙蛋白对Ca²⁺的亲和力；③肌球蛋白ATP酶活性；④能量（ATP）供应。
- 交感神经兴奋、肾上腺素、去甲肾上腺素 → 胞质Ca²⁺↑ → 收缩力↑（正性变力作用）。
- 因为同样的初长度下收缩力变了，所以叫**等长调节（homometric regulation）**。

#### （4）心率

- 安静60~100次/分；
- **40~180次/分范围内**：HR↑→CO↑（因为CO=SV×HR）；
- **HR>180次/分**：舒张期过短→充盈不足→SV明显↓→CO反而↓；
- **HR<40次/分**：舒张末期充盈已饱和，HR再慢CO也上不去。

## 第二章 心肌细胞电生理（正课开场）

### 2.1 为什么要学电生理？——因果链

老师用一条因果链把整章串起来：

> **钠钾泵耗能建立离子梯度（胞外高Na⁺、胞内高K⁺）→ 离子跨膜流动产生电现象（膜电位）→ 动作电位沿心肌传导 → 心肌兴奋-收缩耦联 → 心肌收缩/舒张 → 室内压变化 → 压力梯度 → 瓣膜开关 → 血液流动。**

所以第一节讲的"泵血过程"是**结果**，第二节电生理才是**机制**。老师原话："第二节是本章乃至整本生理学难度最高的部分。"

### 2.2 回顾神经纤维动作电位（第二章内容，老师课堂提问）

老师课堂提问了神经纤维AP的三个问题，作为学心肌AP的脚手架：

1. **RP = -70 mV**（神经细胞）；上升支由**电压门控Na⁺通道**介导Na⁺内流；下降支由**电压门控K⁺通道**介导K⁺外流。
2. **为什么上升支只有Na⁺内流、下降支只有K⁺外流？**——因为**钠通道是瞬时激活（快开快关，开放仅1~2 ms），钾通道是延迟激活**。刺激来临时钠通道立即开放1~2 ms完成上升支；这1~2 ms内钾通道还在"延迟"中没开放；等钾通道延迟结束时，钠通道已经失活关闭。两个通道此消彼长，交替主导。
3. **为什么超射到+30 mV就拐头，不到E_Na（+60 mV）？**——①膜电位到正电位时，Na⁺内流的电驱动力已经大幅减弱（同性相斥）；②此时延迟激活的K⁺通道已经开放，K⁺外流开始占上风；两股电流相等时出现拐点。
4. **为什么AP不衰减传播？**——因为全身每一段细胞膜内外的Na⁺/K⁺浓度梯度都一样，每到一处都用同样的梯度重新"点燃"一个同样幅度的AP。

### 2.3 心肌细胞的分类

| 类型 | 包括 | 收缩性 | 自律性 | 传导性 | 兴奋性 |
|---|---|---|---|---|---|
| **工作细胞** | 心房肌、心室肌 | 有 | 无 | 有 | 有 |
| **自律细胞（特殊传导系统）** | 窦房结P细胞、浦肯野细胞 | 无 | 有 | 有 | 有 |

【考点】本课重点讲两类：**心室肌细胞（工作细胞代表）**和**窦房结P细胞（自律细胞代表）**。

### 2.4 心室肌细胞的静息电位

- **RP ≈ -90 mV**（注意：不是神经细胞的-70 mV！）；
- 形成机制：主要由**内向整流钾通道（I_K1）**介导的K⁺外流形成；
- 老师解释：神经纤维上叫"钾漏通道"，心肌上它有专门名字叫**内向整流钾通道（inward rectifier K⁺ channel, I_K1）**——名字里"内向整流"的具体含义后面讲，本课只要知道"RP由I_K1介导K⁺外流产生，接近E_K（-90 mV）"即可。

### 2.5 心室肌细胞动作电位：五个时期（0、1、2、3、4）

与神经纤维AP"尖峰状、对称、时程短（1~2 ms）"不同，心室肌AP**时程长（200~300 ms）、有平台期**，分5期：

| 时期 | 名称 | 膜电位变化 | 主要离子流 | 通道 | 历时 |
|---|---|---|---|---|---|
| **0期** | 去极化期 | -90 mV → +30 mV | **Na⁺快速内流**（再生式正反馈） | **快钠通道**（电压门控Na⁺通道，瞬时激活） | 1~2 ms |
| **1期** | 快速复极初期 | +30 mV → 0 mV | **K⁺一过性外流** | **瞬时外向钾通道I_to** | 约10 ms |
| **2期** | **平台期** | 0 mV左右平台 | **Ca²⁺缓慢内流 ≈ K⁺外流**（两者平衡） | **L型钙通道**（Long-lasting）+ I_K1（K⁺外流少）+ I_K（延迟整流K⁺外流） | **100~150 ms**（最长） |
| **3期** | 快速复极末期 | 0 mV → -90 mV | **K⁺外流占优势**（Ca²⁺内流停止） | I_K延迟整流K⁺通道开放增加 | 100~150 ms |
| **4期** | 静息期（电舒张期） | 稳定在-90 mV | 钠钾泵、钠钙交换恢复离子梯度 | Na⁺-K⁺-ATP酶、Na⁺/Ca²⁺交换体 | —— |

#### 0期（去极化）

- 有效刺激使膜电位从-90 mV去极到**阈电位（约-70 mV）**；
- 激活一部分**快钠通道**（电压门控Na⁺通道）→ Na⁺内流 → 进一步去极化 → 激活更多钠通道 → **再生式（正反馈）Na⁺内流**；
- 膜电位迅速冲到+30 mV左右；
- 钠通道**一过性激活**（开1~2 ms就失活），0期末已基本失活。

【考点】心室肌0期 = 快Na⁺通道介导Na⁺内流；与神经纤维0期机制相同，但RP起点不同（-90 vs -70）。

#### 1期（快速复极初期）

- 钠通道已失活，出现短暂K⁺外流；
- 由**瞬时外向钾通道I_to**（transient outward K⁺ current）介导；
- 膜电位从+30 mV回落到0 mV左右；
- 历时约10 ms。

#### 2期（平台期）——本课核心难点

这是心室肌AP**最特殊、最重要**的一期：

- **内向电流**：**L型钙通道（L-type Ca²⁺ channel, I_Ca-L）**开放，Ca²⁺缓慢内流（去极化方向）；
- **外向电流**：K⁺外流，但有两个特殊之处——
  - **I_K1（内向整流钾通道）**：在0 mV去极化状态下**反而不愿意开放**（这就是"内向整流"的含义——它喜欢在负电位时开放、在去极化时关闭），所以I_K1介导的K⁺外流在2期**很少**；
  - **I_K（延迟整流钾通道）**：缓慢开放，提供一定量K⁺外流；
- **结果**：Ca²⁺内流（内向）≈ K⁺外流（外向）→ 两股电流平衡 → 膜电位停在0 mV左右形成**平台**；
- 平台早期Ca²⁺内流稍占优；平台晚期L型钙通道缓慢失活关闭，Ca²⁺内流减少，而I_K的K⁺外流逐渐增多 → 平台慢慢结束，过渡到3期。

【考点】**平台期形成机制 = L型Ca²⁺通道Ca²⁺内流 与 K⁺外流（I_K为主）平衡**。这是心室肌AP时程长（200~300 ms）的主要原因。

【考点·临床意义】平台期长 → **心室肌有效不应期特别长**（约200 ms）→ 心肌**不会发生完全强直收缩** → 保证心肌始终"收缩-舒张-收缩-舒张"交替，有充盈间歇，才能有效泵血。这是心肌与骨骼肌（完全强直收缩）的本质区别。

#### 3期（快速复极末期）

- L型钙通道完全关闭 → Ca²⁺内流停止；
- I_K延迟整流K⁺通道充分开放 → K⁺外流迅速增加；
- 膜电位从0 mV快速回到-90 mV。

#### 4期（静息期）

- 心室肌细胞4期电位稳定在-90 mV（非自律细胞无自动去极化）；
- 通过**Na⁺-K⁺泵**（3Na⁺出/2K⁺入）和**Na⁺/Ca²⁺交换体**把动作电位期间内流的Na⁺、Ca²⁺排出去、把外流的K⁺摄回来，恢复离子梯度。

### 2.6 心肌 vs 神经/骨骼肌动作电位对比

| 项目 | 神经纤维/骨骼肌 | 心室肌工作细胞 |
|---|---|---|
| RP | -70 mV | **-90 mV**（I_K1介导） |
| 0期 | Na⁺内流（快钠通道） | Na⁺内流（快钠通道） |
| 1期 | 无明显1期 | **有I_to瞬时K⁺外流** |
| 2期平台 | **无**（尖峰状） | **有！L型Ca²⁺内流≈K⁺外流，100~150 ms** |
| 3期 | K⁺外流 | K⁺外流（I_K） |
| 4期 | 稳定 | 稳定（心室肌）；自律细胞则自动去极 |
| AP时程 | 1~2 ms | **200~300 ms** |
| 有效不应期 | 短 | **长（不发生强直收缩）** |
| 收缩触发 | 钙从SR释放（无外钙内流） | **钙触发钙释放CICR**（L型Ca²⁺内流→触发SR释放Ca²⁺） |

【考点】老师最后特别提醒：**骨骼肌收缩所需Ca²⁺100%来自肌质网释放；心肌收缩所需Ca²⁺有一小部分来自细胞外（L型钙通道内流），这部分外钙再触发肌质网释放更多Ca²⁺——这叫"钙触发钙释放"（calcium-induced calcium release, CICR）**。这就是为什么2期平台期的Ca²⁺内流不仅是电现象，还直接参与心肌收缩。

### 2.7 为什么心肌AP和神经AP图形不一样？

老师强调一个辩证思维：**图形差异不是因为离子梯度不同（所有细胞都是胞外高Na⁺、胞内高K⁺），而是因为细胞膜上表达的离子通道（通透性）不同**——

> **离子流动 = 驱动力（浓度差+电位差）× 通透性（通道是否开放）。** 心肌、骨骼肌、神经纤维的驱动力几乎一样，但表达的通道种类、门控特性完全不同，所以动作电位图形完全不同。

## 第四章 本课必背清单（考前速览）

1. 五个心功能指标：SV 60~80 mL、EF 55~65%、CO 4.5~6.0 L/min、CI 3.0~3.5 L/(min·m²)、心力储备=安静CO的6~7倍。
2. SV=EDV−ESV；EDV≈125 mL、ESV≈55 mL。
3. 影响SV三因素：前负荷（异长调节/Frank-Starling）、后负荷（动脉血压）、心肌收缩能力（等长调节）。
4. Frank-Starling曲线无下降支，结构基础=肌联蛋白+胶原+心肌交错排列。
5. 影响前负荷5因素：充盈时间、静脉回流速度、心室舒张功能、顺应性、心包。
6. 心肌RP=-90 mV（I_K1介导）；神经RP=-70 mV。
7. 心室肌AP五期：0期Na⁺内流（快钠）、1期I_to K⁺外流、2期平台L型Ca²⁺内流≈K⁺外流、3期K⁺外流（I_K）、4期钠钾泵。
8. 平台期意义：AP时程长→有效不应期长→心肌不发生强直收缩→保证泵血。
9. 心肌CICR：L型Ca²⁺内流→触发SR释放Ca²⁺→收缩。
10. 心肌vs骨骼肌：骨骼肌Ca²⁺100%来自SR；心肌有外钙内流参与。

## 第五章 临床联系与深入理解

### 5.1 为什么运动员心脏储备大、心衰患者储备小？

老师在讲心力储备时用了一个很朴素的比喻：心脏安静时只开了5 L/min的"马力"，实际最大能开30 L/min，中间这25 L/min就是储备。

- **运动员**：长期运动训练 → 心肌肥厚但心室腔不狭窄（离心性肥厚）→ 收缩期储备大（ESV能压到20 mL以下）、心率储备大（迷走神经张力高，安静HR可低至50次/分，运动时仍能升到180次）→ 最大CO可达35 L/min以上。
- **心衰患者**：安静时CO已经"顶格"（靠心率偏快、心肌收缩力代偿），储备被提前用光；一旦运动，CO无法随代谢需求上升 → 活动后气促、乏力。这就是为什么心衰患者的主诉是"一动就喘"而不是"安静时喘"。
- **高血压患者**：长期后负荷↑ → 左室向心性肥厚 → 早期EF可正常，但舒张功能首先受损（顺应性↓）→ 表现为活动后呼吸困难；晚期EF下降。

### 5.2 为什么心率太快反而心输出量下降？

CO=SV×HR，看似HR越大CO越大，但这个乘法有前提：**SV不能因为HR上升而大幅下降**。

- HR 75次/分时，舒张期约0.5 s，足够心室充盈；
- HR升到150次/分时，心动周期缩短到0.4 s，收缩期和舒张期都缩短，但**舒张期缩短更明显**（因为舒张期本来就占0.5/0.8≈62%，等容舒张+快速充盈+减慢充盈全在舒张期）；
- HR超过180次/分时，舒张期可能短到0.15 s以下，心室根本来不及充盈 → EDV↓ → SV骤降（可从70 mL降到30~40 mL）；
- 此时即使×180次/分，CO=40×180=7.2 L/min，反而不如HR=120时70×120=8.4 L/min。

【考点】临床上室上速（HR 160~220次/分）患者会出现血压下降、头晕、黑矇，机制就是**心率过快→舒张期充盈不足→CO骤降→脑供血不足**。

### 5.3 为什么心肌不会像骨骼肌那样发生强直收缩？

这是2期平台期在生理学上最重要的意义：

- 骨骼肌AP时程仅1~2 ms，而骨骼肌收缩可达几十~上百毫秒 → 在后一次收缩到来时，前一次收缩早已结束，完全可以总和 → 强直收缩；
- 心室肌AP时程200~300 ms，**其中有效不应期长达200 ms**（几乎覆盖整个收缩期+舒张早期）→ 在有效不应期内，无论多强的刺激都不能引发第二次AP和收缩 → 心肌必须等到舒张期结束才能接受下一次起搏；
- 结果：心肌永远是"收缩0.3 s → 舒张0.5 s → 收缩0.3 s → ……"交替进行，不会出现"锁死在收缩状态" → 保证心室有时间充盈血液。

【考点】**有效不应期长 = 心肌不发生强直收缩 = 保证泵血**。这是心肌电生理最常考的临床意义。

### 5.4 钠通道"瞬时激活、失活"与钙通道"延迟、长时程"——门控特性决定图形

老师花了不少时间讲一个核心思想：**不同通道的门控动力学（开放速度、开放时长、失活速度）决定了AP图形**。

- **快钠通道**：激活快（<0.1 ms）、开放短（1~2 ms即失活）、失活后有不应期。它只在0期短暂工作。
- **L型钙通道**：激活慢（需要去极化到-40 mV才开放，而钠通道-70 mV就开）、开放长（几十~上百 ms才缓慢失活）。它在2期持续工作，提供平台期的内向电流。
- **延迟整流钾通道I_K**：激活慢（去极化后延迟数十 ms才开放）、失活也慢。它在3期才成为主导，完成复极。
- **内向整流钾通道I_K1**：名字最怪——它在静息电位（-90 mV）时开放、介导K⁺外流产生RP；但在0 mV去极化时**反而关闭**（这就是"内向整流"——它只让K⁺内流方向容易通过、不让外流方向通过）。所以2期平台期I_K1帮不上忙，K⁺外流要靠慢节奏的I_K。

这就是为什么老师说"不要死记硬背0、1、2、3、4期每一期是什么电流，要从通道门控特性推导"——知道哪个通道什么时候开、开多久，AP图形自然就推出来了。

### 5.5 药物作用位点预告（后续章节会细讲）

老师在课堂上埋了几个伏笔：

- **钠通道阻滞剂**（如Ⅰ类抗心律失常药奎尼丁、利多卡因）：阻断0期Na⁺内流 → 减慢传导；
- **钙通道阻滞剂**（如维拉帕米、硝苯地平）：阻断L型钙通道 → 减慢2期平台、降低窦房结自律性、扩张血管降压；
- **钾通道阻滞剂**（如胺碘酮）：阻断I_K → 延长复极、延长QT间期；
- **强心苷类**（如洋地黄）：抑制Na⁺/K⁺-ATP酶 → 间接增加胞内Ca²⁺ → 增强心肌收缩力（治疗心衰）；
- **β受体阻滞剂**（如美托洛尔）：阻断交感对心肌的作用 → 降低心率、降低收缩力、降低后负荷。

这些药物后面药理课会细讲，本课只要知道"它们作用在不同离子通道上"即可。
