# 生理学知识框架与思维导图

## 第一章：绪论

```
生理学
├─ 定义：研究机体生命活动现象及功能规律的科学
├─ 研究任务：正常功能 + 机制
├─ 研究层次：整体水平 / 器官系统水平 / 细胞分子水平
├─ 研究方法
│   ├─ 动物实验：急性实验（在体in vivo/离体in vitro）、慢性实验
│   └─ 人体生理研究
├─ 生命基本特征
│   ├─ 新陈代谢（最基本）
│   ├─ 兴奋性（∝1/阈值）
│   ├─ 适应性
│   ├─ 生殖
│   └─ 衰老
├─ 内环境与稳态
│   ├─ 体液 = 体重60%
│   │   ├─ 细胞内液 40%
│   │   └─ 细胞外液 20%（血浆5% + 组织液15% + 淋巴/脑脊液）
│   ├─ 内环境 = 细胞外液（Claude Bernard, 1857）
│   ├─ 稳态 = 相对恒定（Cannon, 1926）
│   │   ├─ 体温36~37℃
│   │   ├─ pH 7.35~7.45
│   │   ├─ 血钾3.5~5.5 mmol/L
│   │   └─ 血糖3.9~6.1 mmol/L
│   └─ 生理意义：维持正常生命活动的必要条件
├─ 生物节律：日节律 / 月节律 / 季节节律
├─ 生理功能调节
│   ├─ 神经调节：反射弧（感受器→传入→中枢→传出→效应器），迅速精确
│   ├─ 体液调节：激素，缓慢持久弥散
│   │   ├─ 远距分泌 / 旁分泌 / 自分泌 / 神经分泌
│   │   └─ 神经-体液调节
│   └─ 自身调节：不依赖神经体液，幅度小局限（肾血流80~180mmHg）
└─ 自动控制系统
    ├─ 反馈（闭环）
    │   ├─ 负反馈：维持稳态（体温37℃、血压、血糖）
    │   └─ 正反馈：活动加速完成（排尿、排便、分娩、凝血）
    └─ 前馈（开环）：预见性（望梅止渴、赛跑前准备）
```

## 第二章：细胞的基本功能——细胞膜物质转运

```
跨膜物质转运
├─ 小分子转运
│   ├─ 被动转运（不耗能，顺浓度差）
│   │   ├─ 单纯扩散
│   │   │   ├─ 物质：O₂、CO₂、N₂、类固醇、乙醇、尿素、水
│   │   │   └─ 特点：脂溶性、不需蛋白、速率快
│   │   └─ 易化扩散
│   │       ├─ 经通道
│   │       │   ├─ 物质：Na⁺、K⁺、Ca²⁺等离子
│   │       │   ├─ 特点：离子选择性、门控特性
│   │       │   │   ├─ 电压门控（神经轴突Na⁺通道）
│   │       │   │   ├─ 化学门控（N₂-ACh受体）
│   │       │   │   └─ 机械门控（耳蜗毛细胞）
│   │       │   └─ 速率：10⁶~10⁸/s
│   │       └─ 经载体
│   │           ├─ 物质：葡萄糖（GLUT）、氨基酸
│   │           ├─ 三特点：结构特异性 / 饱和现象 / 竞争性抑制
│   │           └─ 速率：200~50000/s
│   └─ 主动转运（耗能，逆浓度差）
│       ├─ 原发性主动转运（直接分解ATP）
│       │   ├─ 钠泵（Na⁺,K⁺-ATP酶）
│       │   │   ├─ 3Na⁺出 / 2K⁺入 / 1ATP
│       │   │   ├─ E1↔E2构象循环，周期10ms
│       │   │   ├─ 意义：胞内高K⁺、渗透压容积、生物电基础、继发性转运势能、生电
│       │   │   └─ 抑制：哇巴因、强心苷（地高辛）
│       │   ├─ 钙泵（Ca²⁺-ATP酶）
│       │   │   ├─ PMCA（细胞膜）/ SERCA（肌质网）
│       │   │   └─ 胞质Ca²⁺=0.1~0.2μmol/L
│       │   └─ 质子泵（H⁺,K⁺-ATP酶）
│       │       ├─ 胃壁细胞分泌胃酸
│       │       └─ 抑制：奥美拉唑（PPI）
│       └─ 继发性主动转运（利用Na⁺梯度势能）
│           ├─ 同向转运（symport）
│           │   ├─ Na⁺-葡萄糖（SGLT，小肠/肾小管）
│           │   └─ Na⁺-K⁺-2Cl⁻、Na⁺-I⁻
│           └─ 反向转运（antiport/exchange）
│               ├─ Na⁺-Ca²⁺（NCX，心肌排钙）
│               └─ Na⁺-H⁺（NHE，肾脏排酸）
└─ 大分子转运（膜泡运输，耗能）
    ├─ 出胞（exocytosis）：激素分泌、神经递质释放
    └─ 入胞（endocytosis）：吞噬、吞饮（液相/受体介导）
```

## 第二章：细胞的基本功能——细胞膜电活动

```
生物电（膜电位）
├─ 静息电位（RP）
│   ├─ 定义：安静时膜内负外正（神经细胞-70mV）
│   ├─ 前提：钠泵维持离子不均匀分布
│   │   ├─ 胞内高K⁺（150mmol/L）:胞外低K⁺（5.5）= 30:1
│   │   └─ 胞外高Na⁺（145）:胞内低Na⁺（15）= 10:1
│   ├─ 条件：安静时膜对K⁺选择性通透（钾漏通道）
│   ├─ 机制：K⁺外流 → 内负外正 → K⁺平衡电位（E_K≈-88mV）
│   └─ Nernst公式：E_X = 61.5 log([X]ₒ/[X]ᵢ)
├─ 动作电位（AP）
│   ├─ 定义：有效刺激产生的快速可逆可传播电位波动
│   ├─ 组成
│   │   ├─ 去极相（上升支）：阈电位→Na⁺通道开放→Na⁺内流→正反馈→超射
│   │   ├─ 复极相（下降支）：Na⁺通道失活→K⁺通道开放→K⁺外流
│   │   ├─ 锋电位：去极相+复极相（主要成分）
│   │   └─ 后超极化：K⁺通道延迟关闭
│   ├─ 特征：全或无 / 不衰减传播 / 脉冲式
│   ├─ 阈电位：约-55mV（比RP小10~20mV）
│   └─ 电化学驱动力 = V_m - E_X
│       ├─ 静息时：Na⁺=-130mV（强内向），K⁺=+18mV（弱外向）
│       └─ 超射时：K⁺=+118mV（强外向）
├─ Na⁺学说证据
│   ├─ 改变胞外Na⁺浓度→改变AP峰值
│   ├─ TTX阻断Na⁺通道→上升支消失
│   ├─ TEA阻断K⁺通道→下降支延长
│   └─ 电压钳直接记录离子电流（Hodgkin-Huxley, 1963诺贝尔奖）
├─ 膜电导变化
│   ├─ G_Na：快速一过性（先激活后失活）
│   └─ G_K：缓慢延迟激活（不失活）
├─ 钠通道三状态
│   ├─ 静息态：m门关 / h门开（可激活）
│   ├─ 激活态：m门开 / h门开（Na⁺内流）
│   └─ 失活态：m门开 / h门关（不可激活，须复极化复活）
└─ 临床联系
    ├─ 局部麻醉药（利多卡因）：阻断Na⁺通道→阻滞痛觉传导
    ├─ TTX/TEA：实验工具药
    ├─ 低钙惊厥：Ca²⁺↓→阈电位↓→兴奋性↑
    ├─ 强心苷：抑制钠泵→胞内Na⁺↑→Na⁺-Ca²⁺交换↓→胞内Ca²⁺↑→心肌收缩↑
    └─ 长QT综合征：通道病，复极异常→心律失常
```

## 第二章：细胞的基本功能——动作电位机制与肌细胞收缩（第4课）

```
动作电位机制（前半）
├─ 触发
│   ├─ 刺激三要素：强度（波高）/持续时间（波宽）/变化率（斜率）
│   ├─ 阈强度→阈刺激/阈上刺激/阈下刺激
│   └─ 阈电位：比静息电位小10~20mV（-70→-55mV）
│       ├─ 影响：钠通道密度功能 / 胞外Ca²⁺（高钙上移、低钙下移→手足搐搦）/ 局麻药
├─ 传播
│   ├─ 无髓：局部电流顺序式连续传导（不衰减）
│   ├─ 有髓：郎飞结跳跃式（提速100m/s+节能）
│   └─ 细胞间：缝隙连接→同步化活动（心肌）
├─ 兴奋性及其变化
│   ├─ 可兴奋细胞：神经/肌/腺；兴奋标志=产生AP；阈值∝1/兴奋性
│   ├─ 钠通道三状态：静息（m关h开）/激活（m开h开）/失活（m开h关→复活）
│   ├─ 绝对不应期：兴奋性0，=锋电位，钠通道激活或失活→单向传导+脉冲发放
│   └─ 相对不应期：复极化晚期+后超极化，阈上刺激可兴奋
├─ 电紧张电位（被动电学特性）
│   ├─ 参数：Rm膜电阻/Ri轴向电阻/Cm膜电容
│   ├─ 空间常数λ：1/e≈37%，λ大传得远（髓鞘、大直径）
│   ├─ 时间常数τ：63%/37%，τ小充电快（髓鞘）
│   └─ 极性：负电极→去极化（可生AP）；正电极→超极化
└─ 局部电位（部分通道开放）
    ├─ 三种：终板电位/发生器电位/突触后电位
    ├─ 特点：等级性/衰减性传导/无不应期可总和（时间+空间）/可发生于不产AP细胞
    └─ 与AP关系：总和达阈电位→爆发AP

肌细胞的收缩（后半，新章节）
├─ 神经-肌肉接头
│   ├─ 结构：接头前膜（囊泡ACh+电压门控钙通道）/接头间隙/终板膜（N₂受体+胆碱酯酶）
│   ├─ 传递7步（电-化学-电）：AP→前膜去极→Ca²⁺内流→囊泡出胞释放ACh→结合N₂受体→Na⁺内流K⁺外流→EPP→电紧张扩布→肌膜AP→AChE分解
│   ├─ 量子式释放：1量子=1囊泡；一次AP约125囊泡、2×10⁵通道；mEPP≈0.4mV；冯德培（Ca²⁺依赖+PTP）
│   └─ 影响因素：肉毒杆菌毒素（抑释放）/α-银环蛇毒·箭毒碱·重症肌无力（堵N₂受体）/有机磷（抑AChE）/新斯的明（治疗）
├─ 横纹肌结构
│   ├─ 肌节（Z-Z线）：A带（粗肌丝，收缩不变）/I带（细肌丝，变窄）/H带（变窄消失）/M线/Z线
│   ├─ 肌管系统：横管传AP；纵管SR——LSR回收Ca²⁺、JSR终池释放Ca²⁺（RyR）
│   └─ 三联管（骨骼肌）/二联管（心肌）
├─ 肌丝分子（肌丝滑行学说）
│   ├─ 粗肌丝=肌球蛋白：横桥（ATP酶+结合肌动蛋白，扭动45°，拖动5~15nm）
│   ├─ 细肌丝7:1:1：肌动蛋白（主干）/原肌球蛋白（盖位点）/肌钙蛋白（TnC结合Ca²⁺、TnT固定、TnI按位）
│   └─ 横桥周期4步：结合→发力（释放ADP+Pi）→解离（ATP结合）→复位（ATP分解）；Ca²⁺↑启动、↓停止
├─ 兴奋-收缩耦联
│   ├─ 结构基础：三联管；耦联因子：Ca²⁺
│   ├─ 4步：T管传AP→SR释钙→Ca²⁺触发收缩→SR回收钙
│   └─ 骨骼肌（变构拔塞+RyR1）vs 心肌（钙触发钙释放CICR+RyR2）
└─ 影响收缩效能四因素
    ├─ 前负荷（初长度）：最适初长度（肌节2.0~2.2μm）最大张力；长度-张力曲线（总=主动+被动）
    ├─ 后负荷：先等长后等张；张力-速度曲线（负荷0→Vmax、P₀→速度0）
    ├─ 肌肉收缩能力：与负荷无关的内在特性（Ca²⁺/ATP酶活性/代谢）
    └─ 收缩总和：多纤维总和（大小原则：收缩先小后大、舒张先大后小）+频率总和（单收缩/不完全强直/完全强直，生理几乎全完全强直）
```
