# 生理学知识框架与思维导图

## 第一章：绪论

```
生理学
├─ 定义：研究机体生命活动现象及功能规律的科学
├─ 研究任务：正常功能 + 机制
├─ 研究层次：整体水平 / 器官系统水平 / 细胞分子水平
├─ 研究方法
│   ├─ 动物实验：急性实验（在体in vivo/离体in vitro）、慢性实验
│   └─ 人体生理研究
├─ 生命基本特征
│   ├─ 新陈代谢（最基本）
│   ├─ 兴奋性（∝1/阈值）
│   ├─ 适应性
│   ├─ 生殖
│   └─ 衰老
├─ 内环境与稳态
│   ├─ 体液 = 体重60%
│   │   ├─ 细胞内液 40%
│   │   └─ 细胞外液 20%（血浆5% + 组织液15% + 淋巴/脑脊液）
│   ├─ 内环境 = 细胞外液（Claude Bernard, 1857）
│   ├─ 稳态 = 相对恒定（Cannon, 1926）
│   │   ├─ 体温36~37℃
│   │   ├─ pH 7.35~7.45
│   │   ├─ 血钾3.5~5.5 mmol/L
│   │   └─ 血糖3.9~6.1 mmol/L
│   └─ 生理意义：维持正常生命活动的必要条件
├─ 生物节律：日节律 / 月节律 / 季节节律
├─ 生理功能调节
│   ├─ 神经调节：反射弧（感受器→传入→中枢→传出→效应器），迅速精确
│   ├─ 体液调节：激素，缓慢持久弥散
│   │   ├─ 远距分泌 / 旁分泌 / 自分泌 / 神经分泌
│   │   └─ 神经-体液调节
│   └─ 自身调节：不依赖神经体液，幅度小局限（肾血流80~180mmHg）
└─ 自动控制系统
    ├─ 反馈（闭环）
    │   ├─ 负反馈：维持稳态（体温37℃、血压、血糖）
    │   └─ 正反馈：活动加速完成（排尿、排便、分娩、凝血）
    └─ 前馈（开环）：预见性（望梅止渴、赛跑前准备）
```

## 第二章：细胞的基本功能——细胞膜物质转运

```
跨膜物质转运
├─ 小分子转运
│   ├─ 被动转运（不耗能，顺浓度差）
│   │   ├─ 单纯扩散
│   │   │   ├─ 物质：O₂、CO₂、N₂、类固醇、乙醇、尿素、水
│   │   │   └─ 特点：脂溶性、不需蛋白、速率快
│   │   └─ 易化扩散
│   │       ├─ 经通道
│   │       │   ├─ 物质：Na⁺、K⁺、Ca²⁺等离子
│   │       │   ├─ 特点：离子选择性、门控特性
│   │       │   │   ├─ 电压门控（神经轴突Na⁺通道）
│   │       │   │   ├─ 化学门控（N₂-ACh受体）
│   │       │   │   └─ 机械门控（耳蜗毛细胞）
│   │       │   └─ 速率：10⁶~10⁸/s
│   │       └─ 经载体
│   │           ├─ 物质：葡萄糖（GLUT）、氨基酸
│   │           ├─ 三特点：结构特异性 / 饱和现象 / 竞争性抑制
│   │           └─ 速率：200~50000/s
│   └─ 主动转运（耗能，逆浓度差）
│       ├─ 原发性主动转运（直接分解ATP）
│       │   ├─ 钠泵（Na⁺,K⁺-ATP酶）
│       │   │   ├─ 3Na⁺出 / 2K⁺入 / 1ATP
│       │   │   ├─ E1↔E2构象循环，周期10ms
│       │   │   ├─ 意义：胞内高K⁺、渗透压容积、生物电基础、继发性转运势能、生电
│       │   │   └─ 抑制：哇巴因、强心苷（地高辛）
│       │   ├─ 钙泵（Ca²⁺-ATP酶）
│       │   │   ├─ PMCA（细胞膜）/ SERCA（肌质网）
│       │   │   └─ 胞质Ca²⁺=0.1~0.2μmol/L
│       │   └─ 质子泵（H⁺,K⁺-ATP酶）
│       │       ├─ 胃壁细胞分泌胃酸
│       │       └─ 抑制：奥美拉唑（PPI）
│       └─ 继发性主动转运（利用Na⁺梯度势能）
│           ├─ 同向转运（symport）
│           │   ├─ Na⁺-葡萄糖（SGLT，小肠/肾小管）
│           │   └─ Na⁺-K⁺-2Cl⁻、Na⁺-I⁻
│           └─ 反向转运（antiport/exchange）
│               ├─ Na⁺-Ca²⁺（NCX，心肌排钙）
│               └─ Na⁺-H⁺（NHE，肾脏排酸）
└─ 大分子转运（膜泡运输，耗能）
    ├─ 出胞（exocytosis）：激素分泌、神经递质释放
    └─ 入胞（endocytosis）：吞噬、吞饮（液相/受体介导）
```

## 第二章：细胞的基本功能——细胞膜电活动

```
生物电（膜电位）
├─ 静息电位（RP）
│   ├─ 定义：安静时膜内负外正（神经细胞-70mV）
│   ├─ 前提：钠泵维持离子不均匀分布
│   │   ├─ 胞内高K⁺（150mmol/L）:胞外低K⁺（5.5）= 30:1
│   │   └─ 胞外高Na⁺（145）:胞内低Na⁺（15）= 10:1
│   ├─ 条件：安静时膜对K⁺选择性通透（钾漏通道）
│   ├─ 机制：K⁺外流 → 内负外正 → K⁺平衡电位（E_K≈-88mV）
│   └─ Nernst公式：E_X = 61.5 log([X]ₒ/[X]ᵢ)
├─ 动作电位（AP）
│   ├─ 定义：有效刺激产生的快速可逆可传播电位波动
│   ├─ 组成
│   │   ├─ 去极相（上升支）：阈电位→Na⁺通道开放→Na⁺内流→正反馈→超射
│   │   ├─ 复极相（下降支）：Na⁺通道失活→K⁺通道开放→K⁺外流
│   │   ├─ 锋电位：去极相+复极相（主要成分）
│   │   └─ 后超极化：K⁺通道延迟关闭
│   ├─ 特征：全或无 / 不衰减传播 / 脉冲式
│   ├─ 阈电位：约-55mV（比RP小10~20mV）
│   └─ 电化学驱动力 = V_m - E_X
│       ├─ 静息时：Na⁺=-130mV（强内向），K⁺=+18mV（弱外向）
│       └─ 超射时：K⁺=+118mV（强外向）
├─ Na⁺学说证据
│   ├─ 改变胞外Na⁺浓度→改变AP峰值
│   ├─ TTX阻断Na⁺通道→上升支消失
│   ├─ TEA阻断K⁺通道→下降支延长
│   └─ 电压钳直接记录离子电流（Hodgkin-Huxley, 1963诺贝尔奖）
├─ 膜电导变化
│   ├─ G_Na：快速一过性（先激活后失活）
│   └─ G_K：缓慢延迟激活（不失活）
├─ 钠通道三状态
│   ├─ 静息态：m门关 / h门开（可激活）
│   ├─ 激活态：m门开 / h门开（Na⁺内流）
│   └─ 失活态：m门开 / h门关（不可激活，须复极化复活）
└─ 临床联系
    ├─ 局部麻醉药（利多卡因）：阻断Na⁺通道→阻滞痛觉传导
    ├─ TTX/TEA：实验工具药
    ├─ 低钙惊厥：Ca²⁺↓→阈电位↓→兴奋性↑
    ├─ 强心苷：抑制钠泵→胞内Na⁺↑→Na⁺-Ca²⁺交换↓→胞内Ca²⁺↑→心肌收缩↑
    └─ 长QT综合征：通道病，复极异常→心律失常
```
