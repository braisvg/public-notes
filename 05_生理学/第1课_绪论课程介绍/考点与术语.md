# 生理学第1课 考点与术语

## 高频考点预测

1. **内环境的定义**：细胞外液（血浆+组织液+淋巴液+脑脊液），注意胃液、尿液等与外界相通的液体不属于内环境
2. **稳态的概念**：内环境理化性质的**相对恒定**（不是绝对恒定），动态平衡
3. **体液分布比例**：体液占体重60%；细胞内液40%，细胞外液20%（血浆5%，组织液15%）
4. **负反馈**：维持稳态最主要的调节方式，举例：体温调节（37℃调定点）、血压调节、血糖调节
5. **正反馈**：使生理活动尽快完成，举例：血液凝固、排尿反射、排便反射、分娩
6. **前馈**：预见性调节，举例：望梅止渴、赛跑前准备状态
7. **三种调节方式对比**：神经调节（迅速精确）、体液调节（缓慢持久弥散）、自身调节（幅度小局限）
8. **反射弧五部分**：感受器→传入神经→神经中枢→传出神经→效应器，缺一不可
9. **兴奋性与阈值的关系**：兴奋性∝1/阈值
10. **生物节律**：日节律（体温、皮质醇）、月节律（月经）、季节节律

## 专业术语表

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| 生理学 | physiology | 研究机体生命活动现象及其功能活动规律的科学 |
| 人体生理学 | human physiology | 研究人体功能活动及其规律的科学 |
| 细胞 | cell | 构成人体最基本的结构和功能单位 |
| 急性实验 | acute experiment | 在短时间内对动物标本或整体进行的实验，含在体/离体 |
| 慢性实验 | chronic experiment | 在清醒完整动物上长期反复观察器官功能活动 |
| 在体实验 | in vivo experiment | 在麻醉或清醒动物身上进行的观察实验 |
| 离体实验 | in vitro experiment | 从动物体内取出器官组织在人工环境中观察 |
| 新陈代谢 | metabolism | 机体与环境间物质和能量交换及自我更新过程 |
| 兴奋性 | excitability | 活组织细胞接受刺激产生反应的能力或特性 |
| 刺激 | stimulus | 引起机体或细胞发生反应的内外环境变化 |
| 反应 | response | 刺激引起的机体功能变化（兴奋或抑制） |
| 兴奋 | excitation | 由静止转为活动或活动由弱变强 |
| 抑制 | inhibition | 由活动转为静止或活动由强变弱 |
| 阈值（阈强度） | threshold intensity | 刚能引起组织产生反应的最小刺激强度 |
| 适应性 | adaptability | 机体随环境变化调整生理功能以适应环境的能力 |
| 生殖 | reproduction | 机体繁殖后代、延续种系的功能 |
| 衰老 | aging | 随时间进展结构退行性改变和功能衰退的过程 |
| 体液 | body fluid | 体内所有液体的总称，占体重60% |
| 细胞内液 | intracellular fluid | 分布在细胞内的液体，占体重40% |
| 细胞外液 | extracellular fluid | 分布在细胞外的液体，占体重20% |
| 内环境 | internal environment | 细胞直接生活的液体环境，即细胞外液 |
| 稳态 | homeostasis | 内环境理化性质相对恒定的状态，动态平衡 |
| 生物节律 | biorhythm | 机体功能活动按时间顺序发生周期性变化 |
| 神经调节 | nervous regulation | 通过反射活动调节生理功能，最主要的调节方式 |
| 反射 | reflex | 中枢神经系统参与下对刺激产生的规律性应答 |
| 反射弧 | reflex arc | 反射的结构基础：感受器→传入神经→中枢→传出神经→效应器 |
| 感受器 | receptor | 接受刺激、感受环境变化的特殊结构 |
| 效应器 | effector | 产生反应的器官或组织 |
| 体液调节 | humoral regulation | 化学物质通过体液途径调节靶细胞活动 |
| 远距分泌 | telecrine | 激素经血液循环到达靶细胞 |
| 旁分泌 | paracrine | 化学物质经组织液扩散至邻近细胞 |
| 自分泌 | autocrine | 激素作用于分泌细胞自身 |
| 神经分泌 | neurocrine | 神经细胞分泌激素入血 |
| 神经-体液调节 | neurohumoral regulation | 体液调节作为神经调节传出环节的延伸 |
| 自身调节 | autoregulation | 组织细胞不依赖神经体液的适应性反应 |
| 反馈控制系统 | feedback control system | 输出变量经监测装置回输影响控制部分的闭环系统 |
| 调定点 | set point | 控制系统设定的参考水平（如体温37℃） |
| 负反馈 | negative feedback | 反馈使受控部分活动向原活动相反方向改变 |
| 正反馈 | positive feedback | 反馈使受控部分活动向原活动相同方向改变 |
| 前馈控制系统 | feed-forward control system | 干扰信号在输出变量变化前直接作用于控制部分 |
| 闭环系统 | closed-loop system | 存在反馈回路的控制系统 |
| 恶性循环 | vicious cycle | 病理性的正反馈，使疾病恶化 |
