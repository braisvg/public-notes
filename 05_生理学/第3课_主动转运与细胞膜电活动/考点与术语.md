# 生理学第3课 考点与术语

## 高频考点预测

1. **继发性主动转运分类**：同向转运（symport，如Na⁺-葡萄糖）vs 反向转运（antiport，如Na⁺-Ca²⁺、Na⁺-H⁺）
2. **静息电位产生机制**：钠泵维持浓度梯度→安静时膜对K⁺通透→K⁺外流→内负外正
3. **K⁺平衡电位（E_K）**：约-88mV，接近但略大于实际静息电位（-70mV）
4. **动作电位上升支机制**：阈电位→电压门控Na⁺通道开放→Na⁺内流→正反馈→超射
5. **动作电位下降支机制**：Na⁺通道失活→电压门控K⁺通道开放→K⁺外流→复极
6. **电化学驱动力计算**：= V_m - E_X；静息时Na⁺驱动力-130mV（很强内向），K⁺驱动力+18mV（较弱外向）
7. **Na⁺学说证据**：①改变胞外Na⁺浓度改变峰值；②TTX阻断上升支；③TEA延长下降支；④电压钳直接记录
8. **膜电导变化**：G_Na快速一过性（先激活后失活），G_K缓慢延迟激活（不失活）
9. **钠通道三状态**：静息态（m关h开）、激活态（m开h开）、失活态（m开h关）
10. **阈电位**：比静息电位小10~20mV（神经细胞约-55mV），触发正反馈的临界点
11. **动作电位特征**：全或无、不衰减传播、脉冲式发放
12. **临床联系**：TTX/TEA药理作用、局部麻醉药（利多卡因）阻断Na⁺通道、低钙惊厥、强心苷与Na⁺-Ca²⁺交换

## 专业术语表

| 中文术语 | 英文术语 | 说明 |
|---------|---------|------|
| 同向转运 | symport (cotransport) | 被转运物与Na⁺同方向跨膜的继发性主动转运 |
| 同向转运体 | symporter | 介导同向转运的载体蛋白 |
| 反向转运 | antiport (exchange) | 被转运物与Na⁺反方向跨膜的继发性主动转运 |
| 反向转运体（交换体） | antiporter (exchanger) | 介导反向转运的载体蛋白 |
| Na⁺-葡萄糖同向转运体 | SGLT | 小肠/肾小管吸收葡萄糖的继发性主动转运体 |
| Na⁺-Ca²⁺交换体 | NCX | 3Na⁺入/1Ca²⁺出，心肌舒张排钙 |
| Na⁺-H⁺交换体 | NHE | Na⁺入/H⁺出，肾脏排酸保碱 |
| 生物电 | bioelectricity | 活细胞或组织在生命活动中伴随的电现象 |
| 跨膜电位（膜电位） | transmembrane potential (membrane potential) | 细胞膜内外两侧的电位差 |
| 静息电位 | resting potential (RP) | 安静状态下存在的膜电位，内负外正 |
| 动作电位 | action potential (AP) | 受有效刺激后产生的快速可逆可传播电位波动 |
| 局部电位 | local potential | 阈下刺激产生的小幅度局部电位变化 |
| 极化 | polarization | 静息电位时膜内负外正的状态 |
| 去极化 | depolarization | 膜电位负值减小（向0电位方向） |
| 超极化 | hyperpolarization | 膜电位负值增大（离0电位更远） |
| 复极化 | repolarization | 去极化后向静息电位恢复的过程 |
| 反极化 | reverse polarization | 膜电位变为内正外负 |
| 超射 | overshoot | 膜电位大于0的部分 |
| K⁺平衡电位 | E_K | K⁺净移动为零时的跨膜电位，约-88mV |
| Na⁺平衡电位 | E_Na | Na⁺净移动为零时的跨膜电位，约+60mV |
| Nernst公式 | Nernst equation | 计算离子平衡电位：E_X=61.5log([X]ₒ/[X]ᵢ) |
| 电化学驱动力 | electrochemical driving force | 膜电位与离子平衡电位之差（V_m - E_X） |
| 内向电流 | inward current | 正离子内流或负离子外流，引起去极化 |
| 外向电流 | outward current | 正离子外流或负离子内流，引起复极化 |
| 锋电位 | spike potential | 动作电位的尖锋部分（去极相+复极相） |
| 后超极化 | after-hyperpolarization | 复极后短暂超过静息电位的部分 |
| 全或无 | all or none | 动作电位一旦产生即为最大幅度，不随刺激强度增大 |
| 不衰减传播 | non-decremental conduction | 动作电位传播时幅度不随距离减小 |
| 阈电位 | threshold potential | 触发动作电位的临界膜电位（约-55mV） |
| 阈刺激 | threshold stimulus | 强度恰好等于阈值的刺激 |
| 阈下刺激 | subthreshold stimulus | 强度小于阈值的刺激，只产生局部电位 |
| 阈上刺激 | suprathreshold stimulus | 强度大于阈值的刺激 |
| 电压钳 | voltage clamp | 固定膜电位记录离子电流的技术（Hodgkin-Huxley） |
| 膜片钳 | patch clamp | 记录单通道电流的技术（Neher-Sakmann, 1991诺贝尔奖） |
| 河豚毒 | tetrodotoxin (TTX) | 特异性阻断电压门控Na⁺通道 |
| 四乙胺 | tetraethylammonium (TEA) | 特异性阻断电压门控K⁺通道 |
| 膜电导 | membrane conductance (G) | 膜对离子的通透能力，G=I/(V_m-E_X) |
| 钠通道 | Na⁺ channel | 电压门控，快速激活快速失活 |
| 钾通道 | K⁺ channel | 电压门控，延迟激活不失活 |
| 激活门（m门） | activation gate (m gate) | 钠通道快速开放的门 |
| 失活门（h门） | inactivation gate (h gate) | 钠通道缓慢关闭的门 |
| 静息态（钠通道） | resting state | m门关闭、h门开放，可被激活 |
| 激活态（钠通道） | activated state | m门开放、h门开放，Na⁺内流 |
| 失活态（钠通道） | inactivated state | m门开放、h门关闭，不能被激活 |
| 局部电流 | local current | 兴奋区与邻接未兴奋区之间的电位差形成的电流 |
| 冲动 | impulse | 动作电位在同一细胞上的传播 |
| 局部麻醉药 | local anesthetics | 阻断Na⁺通道（普鲁卡因、利多卡因、丁卡因） |
| 时间性总和 | temporal summation | 连续多个局部电位在时间上叠加 |
| 空间性总和 | spatial summation | 多个局部电位在空间上叠加 |
| 低钙惊厥 | hypocalcemic convulsion | 低血钙使阈电位下移，兴奋性异常增高 |
| 长QT综合征 | long QT syndrome | 钠/钾通道缺陷导致复极延长、心律失常 |
