## 三、全课程知识框架

### 3.1 学科定位
- 统计学 = 数据的收集、整理、分析、解释、表达；
- 卫生统计学 = 统计学原理方法在医学/公共卫生领域的应用；
- 与医学统计学、生物统计学原理方法相同，应用场景不同。

### 3.2 统计工作四步骤
1. **设计**（专业设计 + 统计设计；调查设计 vs 实验设计）
2. **收集资料**（统计报表、日常记录、专题调查/实验；大数据新来源；真实、完整）
3. **整理资料**（双录入、数据清洗、汇总）
4. **分析资料**（统计描述 + 统计推断）

### 3.3 核心概念体系
- 观察单位 → 同质与变异 → 总体与样本 → 参数与统计量 → 变量与资料 → 抽样误差 → 概率
- 资料三分类（重点必考）：
  - 定量（计量/数值变量）：连续型、离散型
  - 定性（分类）：计数（无序：二项/多分类）、等级（有序）

### 3.4 定量资料的统计描述（第2课）
- **频数分布**：频数表编制（全距→组数→组距→组段→归组）、直方图、分布类型（对称/正偏态/负偏态/双峰）
- **集中趋势指标**：
  - 算术均数（X̄）：单峰对称/正态分布；两性质（离均差和为零、离均差平方和最小）；易受极端值影响
  - 几何均数（G）：等比级数（抗体滴度/效价）、对数正态分布；不能有零/不能同时有正负值
  - 中位数（M=P₅₀）：偏态/分布不明/开口资料；不受极端值影响；三条件即非参数方法条件
  - 百分位数（Pₓ）：P₂₅/P₅₀/P₇₅（四分位数）、P₀/P₁₀₀；四分位数间距=P₇₅−P₂₅（离散趋势）
- **指标选择**：正态→均数；等比/对数正态→几何均数；偏态/不明/开口→中位数

### 3.5 离散趋势与正态分布（第3课）
- **离散趋势指标**：
  - 极差（全距）：最大值−最小值；粗糙（只看两端）；样本量增大只增不减；用于单峰对称小样本初步描述/了解范围
  - 四分位数间距（IQR=QU−QL）：中间50%数据的极差；抗极端值强于极差；配中位数（偏态/分布不明/开口资料）
  - 方差：离均差平方和/观测数；总体σ²=Σ(X−μ)²/N、样本s²=Σ(X−X̄)²/(n−1)（n−1为自由度、无偏估计）；离均差之和=0所以要平方
  - 标准差：方差开方、单位还原；配均数（正态/近似正态）
  - 变异系数（CV=s/X̄×100%）：比较单位不同或均数相差悬殊资料的变异程度
- **报告方式**：正态资料"均数±标准差"（±后是标准差不是范围）；偏态资料"中位数（P25~P75）"
- **正态分布**：高斯分布；特征（中间高两边低、左右对称、钟形、x轴为渐近线）；μ位置参数、σ形状参数；面积规律 μ±1σ=68.27%、μ±1.96σ=95%、μ±2.58σ=99%
- **标准正态分布**：Z=(X−μ)/σ；N(0,1)；查表（附表三）用对称性
- **医学参考值范围**：定义（绝大多数正常人波动范围）、默认95%、正常人=同质非病态人群；制定原则6条；正态分布法（双侧X̄±1.96s、单侧X̄±1.64s）vs 百分位数法（偏态：双侧P2.5~P97.5、单侧P5/P95）；质量控制（3s法则）；正态是t检验/方差分析/相关回归的理论基础

### 3.6 定性资料的统计描述（第4课，2026-09-18）
- **常用相对数**：率（频率/强度）、构成比（比重）、相对比（倍数）——三大指标定义/公式/区别
- **率的K比例基数**：100%、1000‰、万、10万（习惯用法或保留1~2位整数）
- **构成比两大特点**：和为100%、此消彼长
- **相对比分类**：对比指标（性别比）、关系指标（床护比）、计划完成指标
- **应用相对数四大注意事项**：分母不宜过小、不能以构成比代替率、合计率不能求平均（分子分母分别合计）、率的比较注意可比性（分层/标准化）
- **动态数列**：累计增长量/逐年增长量、定基比/环比发展速度、增长速度=发展速度−1、平均发展速度=ⁿ√(aₙ/a₀)（几何均数）、平均增长速度=平均发展速度−1
- **率的标准化**：标准化法意义（消除构成影响）、直接法（已知各组率：p'=∑Nᵢpᵢ/N）、间接法（各组率未知：p'=P×SMR，SMR=r/∑nᵢPᵢ）、SMR判读（>1高/<1低）、应用四条注意
- **经典案例**：案例5-1猪链球菌（绝对数不可比）、5-7麻疹（构成比≠率）、5-10高血压（可比性）、5-12埃博拉（标准化动机）、5-13肝癌SMR=13.08

### 3.7 统计推断：参数估计与t分布（第5课，2026-09-22）
- **统计推断总论**：从样本推断总体特征；包括参数估计（点估计/区间估计）和假设检验（下一章，可能需自学）
- **抽样误差**：根本原因=个体变异，直接原因=抽样；不可避免但有规律；两种表现（样本vs总体、样本vs样本）
- **中心极限定理**：正态总体抽样样本均数服从正态；偏态总体 n 足够大时样本均数近似正态
- **标准误**：样本均数的标准差，反映抽样误差大小；公式 S_x̄ = S/√n；与标准差成正比、与√n成反比
- **减小抽样误差**：增大样本含量是唯一方法（执业医师高频）；抽样误差减半需 n 增至4倍
- **标准差vs标准误**（简答题）：含义（个体变异vs均数变异）、用途（参考值范围vs参数估计/假设检验）、公式不同；n一定时成正比
- **t分布**：以0为中心左右对称；一簇曲线（形状与自由度有关）；ν→∞时逼近标准正态分布；曲线下面积=1
- **自由度**：ν = n−1（本节最常用）
- **t界值表**：查表示步（定自由度→定单侧/双侧→定α）；规律（自由度相同t界值越大P越小；P相同自由度越大t界值越小；t值相等双侧概率=2×单侧；ν→∞时t界值=z界值）
- **参数估计**：点估计（直接用样本均数，缺点未考虑抽样误差）；区间估计（置信区间CI，按1−α概率包含总体参数）
- **置信区间三种公式**：σ已知用z、σ未知n>50用z近似、σ未知n<50用t分布
- **单侧vs双侧**：有害物质含量（不高于）、蛋白质含量（不低于）用单侧；一般均数估计用双侧
- **CI含义**：95%CI=做100次抽样约95个区间包含μ；实际做一次有95%把握；α=犯错概率
- **CI两要素**：可信度（1−α）与精确度（区间宽度）；样本量固定时二者矛盾，同时提高只能增大样本量

### 3.8 非参数检验（秩和检验）（第6课，2026-10-13，教师：邓耀台）
- **参数检验vs非参数检验**：参数检验（t检验/方差分析/相关回归）要求总体分布已知（正态、方差齐），资料利用率高检验效能高；非参数检验（卡方检验/秩和检验）不依赖分布类型，适用广但资料利用率低、检验效能低
- **非参数检验三大适用情况**：①不满足参数检验条件（偏态/方差不齐/变换后仍不满足）；②未加精确测量（仪器上下限、有<或>号）；③分布类型未知
- **秩与秩和**：秩=从小到大排序的位次；秩和=各组秩相加；编秩三规则（0值舍去、相持取平均、验算T+ + T− = n(n+1)/2）
- **配对设计Wilcoxon符号秩检验**：差值绝对值编秩、正负分组求秩和、n≤50查附表10（口诀"内大外小"）、n>50用Z近似（分子减0.5、相持>25%校正）
- **单样本Wilcoxon符号秩检验**：样本观测值与已知中位数M₀之差编秩，原理同配对
- **两独立样本Mann-Whitney U检验**：两组混合统一编秩、取小样本组秩和为T、查附表11或Z近似
- **等级资料两样本比较**：各等级合计→秩次范围→平均秩次→频数乘平均秩次求秩和；相持必然>25%需校正
- **多组Kruskal-Wallis H检验**：H=12/[N(N+1)]×Σ(Rᵢ²/nᵢ)−3(N+1)；k=3且每组n≤5查附表12；否则χ²近似（ν=k−1）
- **多组两两比较α校正**：所有两两比较α'=α/[k(k−1)/2]；对照组vs多个实验组α'=α/(k−1)
- **关键易错点**：配对不能当成组、有序等级资料不能用卡方检验、成组设计0值不舍去、大样本查ν=∞列

- 应用场景：临床试验、患病率调查

## 四、备考策略

### 4.1 平时学习
- **概念优先**：这不是数学课，重点理解"抽样误差、Ⅰ/Ⅱ类错误、同质变异、总体样本"等概念；
- **资料分类是基本功**：拿到任何数据先判断属于定量/计数/等级，否则后续方法全错；
- 多做习题，尤其 A2 型综合题（一道题干串多个概念）。

### 4.2 高频考点
- 资料类型判断（必考）；
- 总体、样本、样本量、参数、统计量的辨析；
- 抽样误差原因；
- 小概率事件标准（P<0.05/0.01）；
- 统计四步骤及设计的先导作用（费舍尔名言）；
- 准确性 vs 可靠性；
- 随机抽样、随机分组、配对设计、对照原则；
- **均数两性质**：离均差和为零、离均差平方和最小（关联最小二乘法）；
- **集中趋势指标选择**：正态→均数、等比/对数正态→几何均数、偏态/不明/开口→中位数；
- **几何均数**：抗体滴度/效价直接选G；不能有零、不能同时有正负值；
- **中位数三条件**（=非参数方法条件）：偏态、分布不明、开口资料；
- **百分位数**：P₅₀=中位数、P₂₅/P₇₅=上下四分位数、四分位数间距=P₇₅−P₂₅；
- **正偏态vs负偏态**：看长尾方向，长尾向右=正偏态（右偏）；
- **离散趋势指标选择**：正态→标准差（配均数）；偏态/不明/开口→四分位数间距（配中位数）；单位不同/均数悬殊→变异系数；
- **极差特性**：样本量增大只会变大、不会变小（考试选A题）；
- **样本方差除(n−1)**：自由度、无偏估计（除n会低估）；
- **正态面积规律**：μ±1σ=68.27%、μ±1.96σ=95%、μ±2.58σ=99%；
- **单侧参考值范围用1.64**（不是1.96）：单侧95%上限X̄+1.64s、下限X̄−1.64s；
- **百分位数法界值**：双侧P2.5~P97.5、单侧下限P5、单侧上限P95（偏态资料）；
- **参考值范围**：默认95%、辅助参考不作诊断、"正常人"=排除影响因素的同质人群；
- **报告表达**：正态"均数±标准差"（±后是SD不是范围）；偏态"中位数（P25~P75）"；
- **率vs构成比**：率=频率/强度（可比较）、构成比=比重（和为100%、不可当率用）；
- **合计率**：=总分子/总分母，不能对各组率求平均；
- **直接法vs间接法**：已知各组率→直接法；各组率未知仅有人口数与总死亡数→间接法（SMR）；
- **SMR判读**：>1高于标准、<1低于标准；
- **标准化法注意**：标准不同结论相同；分组率交叉/非平行→不标准化、分层比较；总体比较需假设检验。
- **抽样误差**：根本原因=个体变异；不可避免但有规律
- **标准误**：=样本均数的标准差=S/√n；与标准差成正比、与√n成反比；**增大样本含量是减小抽样误差的唯一方法**（执医高频）
- **标准差vs标准误**（简答题）：含义/用途/公式不同；n一定时成正比
- **t分布特征**：0为中心对称、一簇曲线（与自由度有关）、ν→∞时逼近正态、面积=1
- **自由度**：ν=n−1
- **t界值表规律**：自由度相同t越大P越小；P相同自由度越大t界值越小；t值相等双侧概率=2×单侧；ν→∞时t=z
- **置信区间三公式**：σ已知→z；σ未知n>50→z近似；σ未知n<50→t分布
- **单侧vs双侧**：有害物含量/蛋白含量下限用单侧；一般均数用双侧
- **95%CI含义**：100次抽样约95个区间包含μ；实际做一次有95%把握
- **论文报告**：X̄±SD（标准差），不是X̄±SE；CI写95%CI不要写"Cl/氯气"
- **置信区间两要素**：可信度与精确度矛盾，同时提高需增大样本量
- **非参数检验适用情况**：偏态/方差不齐/分布未知/未精确测量（有<>号）/有序等级资料
- **参数检验vs非参数检验**：参数检验效能高但要求严；非参数适用广但效能低Ⅱ类错误高
- **秩和检验编秩三规则**：差值为0舍去、相持取平均秩次、验算T+ + T− = n(n+1)/2
- **配对设计符号秩检验**：n≤50查附表10，口诀"内大外小"；n>50用Z近似
- **两独立样本秩和检验**：两组混合统一编秩、取小样本组秩和为T
- **等级资料不能用卡方检验**：卡方把各等级当并列类别，丢失顺序信息
- **多组H检验**：k=3且每组n≤5查附表12；否则χ²近似ν=k−1
- **两两比较α校正**：全两两α'=α/[k(k−1)/2]；对照组vs多组α'=α/(k−1)
- **相持>25%必须校正**：Zc=Z/√C，频数表资料几乎必然需要校正

### 4.3 易混点辨析

| 易混对 | 区别 |
|--------|------|
| 准确性 vs 可靠性 | 接近真实值 vs 重复稳定 |
| 总体 vs 样本 | 全部 vs 随机抽取部分 |
| 参数 vs 统计量 | 总体/未知/希腊字母 vs 样本/已知/拉丁字母 |
| 定量 vs 等级 | 数值大小有数量意义 vs 仅有序 |
| 等级 vs 无序多分类 | 有顺序 vs 无顺序（如上中下段管腔） |
| 概率 vs 频率 | 常数 vs 实验估计值 |
| 调查 vs 实验 | 无人为干预 vs 有人为干预 |
| 算术均数 vs 几何均数 | 加法平均（对称分布）vs 乘法平均（等比/对数正态） |
| 几何均数 vs 中位数（极端值题） | 全部数据呈倍数关系→G；少数极端值→中位数 |
| 正偏态 vs 负偏态 | 长尾向右（峰在左）vs 长尾向左（峰在右） |
| 直方图 vs 直条图 | 连续型资料/无间隔/面积表频数 vs 分类资料/有间隔/高度表数值 |
| 均数 vs 中位数 | 利用全部数据/受极端值影响/正态首选 vs 仅中间值/不受极端值影响/偏态首选 |
| 加权法 vs 直接法 | 频数表/组中值/近似值 vs 原始数据/精确值 |
