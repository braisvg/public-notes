## 一、老师强调的考点

### 加权法计算均数
- **【考点】**"加权法的这个权数呢，就是它对应的权数，为什么它是一个权数？因为我们在计算分子的时候，你的 f 越大的话，那它在这个分组里面的成分是不是就越大？所以呢它就起到一个加权的作用。"
- **【考点】**"我们加权法计算出来的均数，它往往是一个近似的值。所以你如果直接把算了，跟你的这个频数表算出来的不一样的话，那非常的正常。但是这种差异呢也就差个 0 点几。如果你发现差很多的话，应该能自己算错数了。"

### 均数的两个性质
- **【考点】**"第一个性质呢，就是离均差之和等于零……每一个观测值和它的均数之间的差，有些人是大于零，有些人是小于零，所以有正有负加起来就变成零。"
- **【考点】**"第二个性质，离均差平方和……小于我们把这个 X̄ 换成一个任意的 A，都比它要小。这个性质更加重要。因为呢，我们后面讲到最小二乘法，也就是我们的回归的一个基本原理之后，其实跟它是有一定关系的。"

### 均数的适用条件
- **【考点】**"均数它适用于描述我们单峰对称分布……只有一个峰，而且以这个峰画一条对称轴的话，两边的频数是对称的。"
- **【考点】**"尤其是这个资料是正态分布或者是近似正态分布资料的话，不用考虑别的了，优先考虑我们的算术均数来描述它的集中趋势。"
- **【考点】**"双峰分布的话，说明它的这个数据本身有异质性，最好把它们分成之后再分别的去分析，而不是用一个均数就去概括它。"
- **【考点】**"均数在描述正态分布的特征方面有重要的意义……正态分布是一个钟形曲线，中间高两边低左右对称，那这个时候它峰的这个位置就是它的均数，所以我们的均数是它的位置常数。"

### 均数的缺点
- **【考点】**"均数有很多毛病，其中一个最重要的毛病是什么呢？就是它很容易受到极端值的影响，譬如说我们有一个词叫做被平均……如果用媒体报道当地人的收入水平，他用的是平均收入的话，那可是他就非常的不专业。"
- **【考点】**"虽然均数的计算很容易受到极端值的干扰，但是因为它有良好的数学性质，使得我们在后续的应用之中会比较方便，所以大家都喜欢用均数来进行描述。"

### 几何均数
- **【考点】**"几何均数的符号呢？用大 G 来表示，它指的是我 n 个观测值之间互相相乘之后再开 n 次方根……所以它又叫做倍数均数。"
- **【考点】**"在我们医学研究里面啊，反正大家看到**滴度和效价**这两个词呢，你就不用想了，直接填我们的几何均数就行了。"
- **【考点】**"对数正态分布就是指它的原变量呢并不服从于正态分布，而且往往是一个正偏态的分布。但是如果你对它每一个取值都取了对数值之后，这个对数值近似于正态分布的话，那我就把这一个变量叫做对数正态分布。"
- **【考点】**几何均数应用：环境监测中有害物质浓度、食品中农药残留、传染病潜伏期——"大部分情况下有害物质出现的机会很少，农药残留大部分都是合格的，偶尔才会出现一些超标；大部分传染病的潜伏期也是比较短的，极个别人的潜伏期会很长。"
- **【考点】**"计算几何均数的时候，首先这个值里面不能有零……如果真的出现零的话，给每一个观测值都加上一个小值，比如说加一个 0.5，算完之后再把这个小值给减掉。"
- **【考点】**"观测值里面不能同时有正值和负值……如果全部都是负数的话，先把这个负号无视掉，把结果算出来之后呢，再把这个负号请回来。"

### 中位数
- **【考点】**"中位数的符号用大写 M 表示……一组数据由小到大排序之后，位置居中的这个数值就是它的中位数。它更多像是观察出来的，所以它是一个位置的指标。"
- **【考点】**"中位数它看各种极端骚扰的能力很强……就算你这里面塞了个富豪在里面，是不是也不怕，因为他有多少钱，都不会影响你坐中间位置的人。"
- **【考点】**"我们仍然不是首选中位数，而是首选算术均数。这个就是因为算术均数在某些数学性质上面有一些优良的传统，使得我们可以在它的基础之上开发出很多统计方法。但是中位数在这一点上面呢就比较难。"
- **【考点·三条条件·必考】**"中位数用在什么情况下呢？就是这三个条件……①偏态分布资料；②分布类型不明的资料；③开口资料。这一个不仅仅是我们中位数的条件，我们后面凡是讲到非参数方法，它的这个条件的话，也是这三条啊。"

### 百分位数
- **【考点】**"百分位数的意思就是把我们一组观测值由小到大排序之后，将其平均为100个等份，对应每个分割位置上面的数值，我们就叫做某一个百分位数，符号用 Pₓ 来表示。"
- **【考点】**"中位数又叫做第50百分位数……下四分位数是第25百分位数，上四分位数是第75百分位数。这三个数字加起来就合称叫做四分位数。"
- **【考点】**"第0分位数是最小值，第100分位数是最大值。"
- **【考点】**"我们下节课马上会讲到用这个75分位数减25分位数，得到这个差呢，叫做四分位数间距，它也是一个拿来描述我们资料的离散趋势的一个指标。"

### 课堂易错题
- **【考点·易错题】**"少数几个数据比大部分大几百倍"→ 选中位数（不是几何均数！）。老师原话："大部分选错都选择B几何均数……看到个倍数，条件反射就选B……其实少数几个数据比大部分大几百倍，那说明这几个数据叫做极端值或者说可疑值，这种情况下应该用中位数。如果是真的是几何均数的话，那这些数据之间是不是要成一种倍数的关系啊？"

## 二、中英对照术语表

| 中文 | 英文 | 说明 |
|------|------|------|
| 集中趋势 | Central tendency | 一组数据的中心位置或平均水平 |
| 平均数 | Average | 集中趋势指标的总称，含算术均数、几何均数、中位数等 |
| 算术均数（均数） | Arithmetic mean / Mean | 观测值之和除以n；样本X̄，总体μ |
| 样本均数 | Sample mean | X̄ (x-bar) |
| 总体均数 | Population mean | μ (mu) |
| 加权法 | Weighted method | 用频数表组中值×频数计算均数的方法 |
| 权数 | Weight / Frequency (f) | 各组段的频数，反映该组在总体中的比重 |
| 组中值 | Class mid-value (X₀) | (下限+相邻较大组下限)/2，组段代表值 |
| 离均差 | Deviation from mean | x − X̄，观测值与均数之差 |
| 离均差平方和 | Sum of squared deviations | Σ(x−X̄)²，具有最小值性质 |
| 最小二乘法 | Least squares method | 使残差平方和最小的参数估计方法，回归分析基础 |
| 单峰对称分布 | Unimodal symmetric distribution | 只有一个峰且左右对称的分布 |
| 双峰分布 | Bimodal distribution | 有两个峰的分布，提示数据异质性，应分组分析 |
| 正态分布 | Normal distribution | 钟形曲线，中间高两边低左右对称；均数为位置常数 |
| 极端值 | Outlier / Extreme value | 远离数据主体的观测值，严重影响均数 |
| 被平均 | — | 极端值拉高均数导致均数不能代表典型水平的现象 |
| 几何均数 | Geometric mean (G) | n个观测值乘积开n次方；又称倍数均数 |
| 倍数均数 | — | 几何均数的别称 |
| 等比级数（几何级数） | Geometric series | 观测值之间呈倍数关系的数列 |
| 对数正态分布 | Log-normal distribution | 原变量正偏态，取对数后近似正态分布 |
| 抗体滴度 | Antibody titer | 血清中抗体浓度的表示方法，呈等比关系 |
| 效价 | Potency / Titer | 药物或生物制品活性的表示，呈等比关系 |
| 对数变换 | Logarithmic transformation | 对观测值取对数，将乘法变加法、偏态变对称 |
| 反对数 | Antilogarithm | 对数的逆运算，即10的对数次方 |
| 中位数 | Median (M) | 排序后位次居中的观察值 = P₅₀ |
| 位置指标 | Position measure | 中位数是位置指标，由排序定位而非计算得出 |
| 开口资料 | Open-ended data | 一端或两端无确定值的资料（如">5年"） |
| 偏态分布 | Skewed distribution | 不对称分布，分正偏态（右偏）和负偏态（左偏） |
| 正偏态（右偏） | Positively skewed / Right-skewed | 峰在左，长尾向右，极端大值 |
| 负偏态（左偏） | Negatively skewed / Left-skewed | 峰在右，长尾向左，极端小值 |
| 百分位数 | Percentile (Pₓ) | x%的观察值≤该值 |
| 第50百分位数 | 50th percentile (P₅₀) | 即中位数M |
| 下四分位数 | Lower quartile (Q₁ / P₂₅) | 第25百分位数 |
| 上四分位数 | Upper quartile (Q₃ / P₇₅) | 第75百分位数 |
| 四分位数 | Quartiles | P₂₅、P₅₀、P₇₅三个数的合称 |
| 四分位数间距 | Interquartile range (IQR / Q) | P₇₅ − P₂₅，描述偏态资料离散趋势（下节课内容） |
| 非参数方法 | Nonparametric method | 不依赖总体分布类型的统计方法，适用条件同中位数三条件 |
| 秩和检验 | Rank sum test | 常用非参数检验方法（后续讲） |
| 频数分布表 | Frequency distribution table | 按组段分组后清点各组频数形成的表格 |
| 全距（极差） | Range (R) | 最大值 − 最小值 |
| 组距 | Class interval (i) | 相邻两组段下限之差 |
| 组段 | Class interval | 数据分组的区间，下限闭上限开 |
| 累计频数 | Cumulative frequency | 从第一组到某组的频数之和 |
| 插值法 | Interpolation method | 频数表法计算中位数/百分位数的方法，假设组内均匀分布 |
| 医学参考值范围 | Medical reference range | 绝大多数正常人的某项指标所在范围（后续讲） |
| 离散趋势 | Dispersion / Variability | 数据离开集中位置的程度（下节课内容） |
| 方差 | Variance | 离均差平方和除以n（或n−1）（下节课内容） |
| 标准差 | Standard deviation (SD) | 方差的平方根（下节课内容） |
| 变异系数 | Coefficient of variation (CV) | 标准差/均数×100%（下节课内容） |
