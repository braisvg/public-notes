## 一、考点清单（保留老师原话）

### 考点1：参数检验vs非参数检验定义

【考点】老师原话："参数检验是指样本来自的总体分布是已知的，比如正态分布的总体，在此基础上对未知总体参数进行估计或检验。非参数检验不依赖于总体分布类型，只是通过样本观察值比较总体分布或分布位置的检验。"

- 常见参数检验：t检验、方差分析、直线相关回归
- 常见非参数检验：卡方检验、秩和检验

### 考点2：参数检验与非参数检验优缺点

【考点】老师原话："参数检验资料利用率高、检验效能高，但对总体分布要求严格、适用范围窄。非参数检验对分布类型不做要求、适应性广，但资料利用率低、检验效能相对较低，Ⅱ类错误会比较高。"

### 考点3：非参数检验的三大适用情况

【考点】老师原话："不满足参数检验条件的（正态、方差齐不满足，变换后仍不满足）；未加精确测量的（仪器检测上下限、有<或>号的数据）；分布类型未知的资料。"

### 考点4：不能只学非参数检验

【考点】老师原话："有同学想，既然非参数检验适用范围这么广，我能不能只学非参数检验一套方法做所有统计？显然不能。满足参数检验条件优选参数检验，不满足才用非参数。"

### 考点5：秩和检验是"打补丁"

【考点】老师原话："可以简单把非参数检验当成之前学的检验打了个补丁——适合的优选，不适合的也要做检验，就用非参数。"

### 考点6：编秩基本规则

- 差值为0：不参与编秩，n减去这些例数
- 相同数值（相持/结）：取平均秩次，如排第2、3位则秩次=(2+3)/2=2.5
- 验算：T+ + T- = n(n+1)/2（配对）；T₁+T₂=N(N+1)/2（成组）

### 考点7：配对设计Wilcoxon符号秩检验

【考点】老师原话："差值的计算必须同一个方向减下来，比如乙法减甲法所有都要乙法减甲法。编秩注意是绝对值从小到大编，不是原始值。"

- 查表法：n≤50查附表10
- 口诀"内大外小"：T在界值范围内→P>α；范围外→P<α
- 大样本（n>50）：用Z正态近似，分子减0.5连续性校正
- 相持>25%：分母校正除以√C

### 考点8：配对设计与成组设计编秩三点不同

【考点】老师原话："第一，成组设计把两组数据混合从小到大统一编秩，不是先算差值再编；第二，检验统计量取样本例数较少那组的秩和T；第三，H₀成立时T应接近n₁(n₁+1)/2。"

### 考点9：成组设计0值不舍去

【考点】老师原话："成组设计中0是具体观测值的一部分，没有说0舍去这一点。与配对设计不同，配对差值为0对统计运算没用，但成组的0是数据本身。"

### 考点10：等级资料不能用卡方检验

【考点】老师原话："对于有顺序的、单调增或单调减的有序资料，不能直接用卡方检验，要用秩和检验。卡方检验把治愈、显效、有效当成互不相容的并列类别，丢失了等级顺序信息，检验效能反而下降。"

### 考点11：等级资料编秩方法

1. 各等级合计频数
2. 确定秩次范围（如1~32、33~63……）
3. 平均秩次=(下限+上限)/2
4. 各组秩和=平均秩次×各组该等级频数，再求和
5. 频数表资料相持必然>25%，必须校正

### 考点12：多组H检验查表条件

【考点】老师原话："查表法适用k=3组且每组样本数≤5。k=3且最少样本数>5或k>3时，H近似服从自由度k−1的卡方分布，查卡方界值表。"

### 考点13：多组比较后的两两比较α校正

【考点】老师原话："所有组间两两比较用α除以k(k−1)/2；一个对照组与多个实验组比较用α除以k−1。"

### 考点14：多组检验假设表述

- H₀：各总体分布位置相同
- H₁：各总体分布位置**不同或不全相同**（注意：不是"两两都不同"）

### 考点15：大样本查ν=∞列

【考点】老师原话："大样本正态近似法算出来的Z值，查t界值表在正无穷那一列（即标准正态分布）。"

### 考点16：老师最后总结

【考点】老师原话："秩和检验对总体分布、方差齐都不做要求。两个独立样本比较时，优先看是否符合t检验条件，能用t检验就用t检验，用不了才用秩和检验。重点难点在编秩和求秩和是否正确，课后盖住书本例题自己重算一遍。"

## 三、公式速查

### 3.1 配对/单样本符号秩检验

```
验算：T+ + T− = n(n+1)/2

小样本（n≤50）：查附表10

大样本（n>50）：
Z = (|T − n(n+1)/4| − 0.5) / √[n(n+1)(2n+1)/24]

相持校正（相持>25%）：
C = 1 − Σ(tⱼ³−tⱼ) / (n³−n)
Zc = Z / √C
```

### 3.2 两独立样本秩和检验

```
验算：T₁ + T₂ = N(N+1)/2，N=n₁+n₂
检验统计量T = 样本例数较少那组的秩和

小样本：查附表11（n₁≤10 或 n₂−n₁≤10）

大样本：
Z = (|T − n₁(N+1)/2| − 0.5) / √[n₁n₂(N+1)/12]
```

### 3.3 多组Kruskal-Wallis H检验

```
H = 12 / [N(N+1)] × Σ(Rᵢ²/nᵢ) − 3(N+1)

相持校正：Hc = H / C
C = 1 − Σ(tⱼ³−tⱼ)/(N³−N)

推断：k=3且每组n≤5查附表12；否则查χ²界值表（ν=k−1）
```

### 3.4 两两比较α校正

```
所有组间两两比较：α' = α / [k(k−1)/2]
对照组 vs 多个实验组：α' = α / (k−1)
```
