## 第一部分：统计方法选择总论（教材第十一章导入）

### 1.1 为什么要学如何选择统计方法？

老师开场即强调：**选择正确的统计方法很重要**。拿到一道题目，不能上来就算，要系统判断用什么方法。

【考点】老师原话："选择正确的统计方法很重要，但是一直也没机会跟大家说到底如何选择，我们应该考虑这些点，今天系统地跟大家说一下到底如何选择正确的统计方法。"

### 1.2 选择统计方法的四个判断维度

拿到数据后依次问自己四个问题：

1. **研究目的是什么？**——是估计总体均数/率？还是比较两组/多组间有无差异？相关回归？
2. **资料类型是什么？**——定量资料（有数值有单位）？定性资料（计数）？等级资料（有序分类）？
3. **设计类型是什么？**——单样本？配对设计？成组（两独立样本）？完全随机设计多组？随机区组？
4. **样本量大小和适用条件是否满足？**——正态吗？方差齐吗？n够大吗？

【考点】老师原话："我们要看我们求的目的是什么……根据资料的类型是定性还是定量……再看设计类型是单样本、配对还是成组……以及样本量大小，再根据各个统计方法的适用范围，综合考虑选到适合的统计方法。"

### 1.3 复习：t检验的适用条件（老师带回顾）

t检验有三个前提：

- **样本来自正态总体**（最基本前提）
- **总体标准差σ未知**，用样本标准差S估计
- **样本量较小**（n<50）
- **两组比较时还要求方差齐性**

【考点】老师原话："t检验一般需要样本来自正态总体，这是最基本的前提；第二点是总体σ未知且n比较少，少于50；第三点是两个样本比较时还需要方差齐才可以用t检验。"

## 第二部分：参数检验 vs 非参数检验

### 2.1 什么是参数检验？

**参数检验（parametric test）**：样本来自的总体分布类型已知（如正态分布），在此基础上对未知的总体参数（如μ、σ）进行估计或假设检验。

常见的参数检验包括：
- t检验（单样本、配对、两独立样本）
- 方差分析（F检验）
- 直线相关与回归

### 2.2 什么是非参数检验？

**非参数检验（nonparametric test）**：不依赖于总体分布类型，不对总体参数进行推断，而是通过样本观察值直接比较总体的**分布位置或分布形态**是否相同的检验方法。

常见的非参数检验包括：
- **卡方检验**（上节课学的，属于非参数检验）
- **秩和检验**（本课重点）

【考点】老师原话："参数检验是指样本来自的总体分布是已知的，比如正态分布的总体，在此基础上对未知总体参数进行估计或检验。非参数检验不依赖于总体分布类型，只是通过样本观察值比较总体分布或分布位置的检验。"

### 2.3 参数检验与非参数检验的优缺点对比

| 对比维度 | 参数检验 | 非参数检验 |
|---------|---------|-----------|
| 对总体分布要求 | 严格（正态、方差齐） | 不做要求 |
| 适用范围 | 较窄 | 广（任何资料类型） |
| 资料利用率 | 高（充分利用原始数值信息） | 低（只利用秩次，丢失数值大小信息） |
| 检验效能 | 高 | 相对较低（Ⅱ类错误β较高） |
| 前提不满足时 | 不能用 | 可作为"补救"方法 |

【考点】老师原话："参数检验资料利用率高、检验效能高，但对总体分布要求严格、适用范围窄。非参数检验对分布类型不做要求、适应性广，但资料利用率低、检验效能相对较低，Ⅱ类错误会比较高。"

### 2.4 老师的关键提醒：不能"一套方法做所有统计"

【考点】老师原话："有同学想，既然非参数检验适用范围这么广，我能不能只学非参数检验，一套方法把所有统计都做出来？显然不能。如果满足参数检验条件，优选参数检验；不满足条件时才用非参数检验。因为涉及资料利用率和Ⅱ类错误概率的问题。"

老师将非参数检验比喻为**"打补丁"**："适合参数检验的优选参数检验；不适合的，也要做检验，就用非参数检验打个补丁。"

## 第三部分：秩与秩和的基本概念

### 3.1 什么是秩？

**秩（rank）**：将数据从小到大排序后，每个数据所处的位次（顺序号）。

例如有数据：3、4、9、11、24
从小到大排列后位次为：1、2、3、4、5
这就是秩。

【考点】老师原话："什么是秩？顾名思义就是把数字从小到大排序，这种顺序在统计学上就叫秩。"

### 3.2 什么是秩和？

**秩和（rank sum）**：将各组的秩相加所得之和。

这是秩和检验最基础的统计量，后续各种编秩方法都是基于这个原理演变而来。

【考点】老师原话："什么是秩和？把秩相加就是秩和。后续很多编秩方法都是基于这种演变过来的。"

### 3.3 编秩的三条基本规则

1. **差值为0不参与编秩**——有效对子数n减去差值为0的例数
2. **相同数值（相持/结）取平均秩次**——如两个数分别排第2和第3位，秩次均为(2+3)/2=2.5
3. **秩和验算**：T+ + T- = n(n+1)/2（n为有效例数）

## 第四部分：非参数检验的适用条件（三大类资料）

老师明确讲了什么时候必须用非参数检验：

### 4.1 第一类：不满足参数检验条件的资料

- 正态性不满足（偏态分布）
- 方差不齐
- 经过变量变换（如对数变换）后仍不满足正态性

### 4.2 第二类：未加精确测量的资料

- 仪器检测有下限和上限
- 数据中有"<"或">"号（如"<0.01 mg/L"）
- 没有具体数值的资料

【考点】老师原话："一台血生化仪有检测上限和下限，一份血样指标低于检测下限或高于上限，这种没有具体数值的资料，不能用参数检验，必须用非参数。"

### 4.3 第三类：分布类型未知的资料

- 背景不明，不知道总体分布是什么
- 不满足参数检验的前提条件
- 常见做法就是秩和检验

【考点】老师原话："以上三种情况是常见的做秩和检验的类型，可以在书上画一画记一记。"

## 第五部分：配对设计Wilcoxon符号秩检验（教材例11-1）

### 5.1 方法概述

**Wilcoxon符号秩检验（Wilcoxon signed-rank test）**：由美国统计学家Frank Wilcoxon于1945年提出，用于配对设计资料的比较。

### 5.2 例题11-1：甲乙两种方法测尿汞值

- **设计类型**：配对设计（同一样品用甲乙两种方法分别检测）
- **资料类型**：定量资料（尿汞值，有具体数值和单位）
- **为什么不能用配对t检验？**——配对差值呈偏态分布（直方图右侧有长尾，不对称）
- **原医师错误**：①把配对设计当成成组设计处理；②偏态数据用了t检验

【考点】老师原话："配对设计统计的是对子之间的差值。这个差值做频数表后，右边还有一块，显然不是正态分布，所以差值不是正态分布，不能用t检验，需要用秩和检验。"

### 5.3 检验步骤（三步走）

**第一步：建立假设，确定检验水准α**
- H₀：差值的中位数M_d = 0（两种方法检测结果相同）
- H₁：M_d ≠ 0（两种方法检测结果不同）
- α = 0.05（双侧）

**第二步：计算检验统计量T**

1. 求各对差值d = 乙法 − 甲法（注意：所有对子必须统一方向，不能一会甲减乙、一会乙减甲）
2. 按**差值的绝对值**从小到大编秩
3. 差值为0的对子舍去，n减去这些例数
4. 绝对值相同（相持）的取平均秩次
5. 按差值的正负分别求秩和：正秩和T+、负秩和T-
6. **验算**：T+ + T- = n(n+1)/2
7. 任取T+或T-作为检验统计量T

【考点】老师原话："差值的计算必须是同一个方向减下来的，比如乙法减甲法，所有都要乙法减甲法。编秩时注意是绝对值从小到大编，不是原始值。"

**第三步：确定P值，作出推断**

- **小样本查表法**（n≤50）：查教材附表10（Wilcoxon符号秩检验界值表，约435页）
- 以有效对子数n查对应行，根据α查对应范围
- **记忆口诀："内大外小"**——T值落在界值范围之内→P>α；落在范围之外→P<α
- α越小，界值范围越宽（因为小概率事件在范围之外，可信度越高越需要远离）

### 5.4 本例结果

- n=10（有效对子数，11对减去1对差值为0）
- T+和T-落在α=0.05与α=0.1对应的界值之间
- 按α=0.05水准，不拒绝H₀
- **结论：尚不能认为甲乙两种方法检测尿汞值有差别**

### 5.5 大样本正态近似法（n>50时）

当对子数n>50时，T值近似服从正态分布，用Z检验：

```
Z = (|T − n(n+1)/4| − 0.5) / √[n(n+1)(2n+1)/24]
```

- 分子中减去0.5是连续性校正
- 当相持（相同秩次）个数超过总例数25%时，需进一步校正分母：
  - 校正因子C = 1 − Σ(tⱼ³ − tⱼ) / (n³ − n)
  - 校正后Zc = Z / √C

【考点】老师原话："算完秩之后要看有没有相持。如果没有相持用哪个公式，如果相持超过25%又用哪个。编完秩之后不是统一方法来做，还得看秩相似的多不多。"

### 5.6 基本思想

与配对t检验类似，但不同点在于：
- 配对t检验针对**具体差值**
- Wilcoxon符号秩检验把差值转换为**秩**，针对秩进行检验
- H₀成立时，T+与T-应该差不多大，且接近平均秩和n(n+1)/4
- 如果T+和T-相差悬殊，远离平均秩和，则怀疑H₀

## 第六部分：单样本Wilcoxon符号秩检验（教材例11-2）

### 6.1 方法目的

推断样本所来自的总体中位数M与已知总体中位数M₀是否相同。

### 6.2 例题11-2：脱发患者头发铜含量

- **已知**：某地健康人群头发铜含量中位数M₀=11.5（μg/g）
- **样本**：抽取脱发患者若干例，测头发铜含量
- **资料类型**：定量资料，偏态分布（脱发人群铜含量偏低）
- **设计类型**：单样本设计
- **原医师错误**：用了单样本t检验，但数据偏态不满足正态性

### 6.3 检验步骤

1. H₀：脱发患者头发铜含量中位数M = 11.5
2. H₁：M < 11.5（单侧检验，因专业知识提示脱发者铜偏低）
3. α = 0.05
4. 各观测值减去M₀=11.5，得到差值
5. 对差值的绝对值编秩，正负分组
6. 本例T+=4，T-=51（差距悬殊，初步判断有差异）
7. 查附表10（n=10，单侧），得0.005 < P < 0.01
8. 按α=0.05水准，拒绝H₀，接受H₁
- **结论：脱发患者头发铜含量低于健康人群**

【考点】老师原话："单样本符号秩检验与配对的原理差不多，不同点在于：配对的差值来自样本对子之间；单样本的差值来自每个观测值与已知总体中位数M₀之差。"

## 第七部分：成组设计两样本比较的秩和检验（Mann-Whitney U检验，教材例11-3）

### 7.1 方法概述

用于推断两个独立样本所来自的总体分布位置是否相同。对应两独立样本t检验的非参数版本。

### 7.2 例题11-3：新疗法vs传统疗法治疗流行性出血热

- **设计类型**：成组设计（两独立样本，新疗法10例，传统疗法12例，例数可不相等）
- **资料类型**：定量资料，偏态分布（退热时间不呈正态）
- **疗效指标**：用药开始至体温降至正常的时间
- **原医师错误**：用了成组t检验，但数据偏态

### 7.3 编秩方法（与配对设计的三点不同）

【考点】老师强调三点不同：

1. **编秩对象不同**：配对设计先算差值再编秩；成组设计把两组所有数据**混合在一起从小到大统一编秩**
2. **检验统计量取法不同**：配对设计T+或T-任取；成组设计取**样本例数较少那组**的秩和作为检验统计量T
3. **判断基准不同**：成组设计中，若H₀成立（两组来自同一总体），T应接近n₁(n₁+1)/2

### 7.4 编秩步骤

1. 将两组全部数据混合，从小到大统一编秩
2. 相同数值（相持）取平均秩次
3. **注意**：成组设计中数据为0不舍去（0是具体观测值的一部分，不像配对差值为0无意义）
4. 分别求两组秩和T₁和T₂
5. 验算：T₁ + T₂ = N(N+1)/2（N=n₁+n₂为总例数）
6. 两组例数相等时任取一组秩和；不等时取例数较少那组的秩和作为检验统计量T

### 7.5 本例结果

- n₁=10（新疗法），n₂=12（传统疗法）
- T₁=66.5，T₂=186，验算66.5+186=252.5≈22×23/2=253
- 查附表11（两样本比较秩和检验界值表）：n₁=10，n₂−n₁=2
- P < 0.01
- 按α=0.05，拒绝H₀，接受H₁
- **结论：两种疗法退热时间不同（新疗法效果更好）**

### 7.6 大样本正态近似法

当n₁>10或n₂−n₁>10时，用Z检验：

```
Z = (|T − n₁(N+1)/2| − 0.5) / √[n₁n₂(N+1)/12]
```

相持超过25%时同样需校正：Zc = Z / √C

## 第八部分：频数表（等级）资料两样本比较的秩和检验（教材例11-4）

### 8.1 例题11-4：中药治疗病毒性vs细菌性小儿肺炎

- **设计类型**：完全随机设计（两组独立）
- **资料类型**：**有序等级资料**（疗效：痊愈→显效→好转→无效）
- **例数**：病毒性肺炎62例，细菌性肺炎60例
- **原医师错误**：用了行×列表卡方检验——卡方检验把各等级视为互不相容的并列类别，**丢失了等级顺序信息**

【考点】老师原话："对于有顺序的、单调增或单调减的有序资料，不能直接用卡方检验，要用秩和检验或Ridit分析。卡方检验认为结局是相互并列的关系，但这里治愈、显效、有效之间是有内在等级联系的。"

### 8.2 等级资料编秩方法（关键！）

1. **各等级合计频数**：每行（每个疗效等级）计算总例数
2. **确定各组的秩次范围**：如第一等级1~32，第二等级33~63，依次累加
3. **求平均秩次**：每个等级的平均秩次 = (秩次范围下限 + 秩次范围上限) / 2
4. **计算各组秩和**：每组各等级的（平均秩次×该组该等级频数）求和
5. **验算**：T₁+T₂ = N(N+1)/2

### 8.3 统计量计算与结论

- 本例n₁=62，n₂=60，N=122
- 相持比例高（同一等级内多个相同秩次），**必须校正**
- Zc=2.6159，查t界值表ν=∞列（即标准正态），P<0.01
- 比较各组平均秩次：病毒性肺炎平均秩次=53.51，细菌性肺炎平均秩次=69.7
- **平均秩次小者疗效更好**（因为痊愈编在最小编秩方向）
- **结论：该中药对病毒性肺炎疗效优于细菌性肺炎**

【考点】老师原话："频数表的秩和检验，相持肯定超过25%，肯定需要校正。算出来的Zc查t界值表ν=∞那一列。"

## 第九部分：完全随机设计多样本比较的秩和检验（Kruskal-Wallis H检验，教材例11-5）

### 9.1 方法概述

**Kruskal-Wallis H检验（KW检验）**：用于推断多个独立样本所来自的总体分布位置是否相同。对应单因素方差分析的非参数版本。

### 9.2 例题11-5：某种胶囊对血管性痴呆大鼠海马SOD活性的影响

- **设计类型**：完全随机设计（4组独立样本：对照组、低剂量组、中剂量组、高剂量组，每组8只，共32只）
- **资料类型**：定量资料，**非正态分布且方差不齐**
- **原医师错误**：用了单因素方差分析（F=46.162, P=0.001），但前提条件不满足
- **正确方法**：完全随机设计多样本秩和检验（H检验）

### 9.3 检验假设

- H₀：四组大鼠SOD活性的总体分布位置相同
- H₁：四组总体分布位置**不同或不全相同**（注意：多组比较只说明"至少两组不同"）
- α = 0.05

### 9.4 H统计量计算公式

```
H = 12 / [N(N+1)] × Σ(Rᵢ²/nᵢ) − 3(N+1)
```

- N = 总例数，k = 组数，nᵢ = 第i组例数，Rᵢ = 第i组秩和
- 有相持时需校正：Hc = H / C，其中 C = 1 − Σ(tⱼ³−tⱼ)/(N³−N)

### 9.5 编秩步骤

1. 各组数据混合，从小到大统一编秩
2. 相同数值取平均秩次
3. 分别计算各组秩和Rᵢ和例数nᵢ
4. 代入H公式计算

### 9.6 本例结果

- N=32，k=4
- H=26.47，校正后Hc=26.48
- **查表法适用条件**：k=3组且每组n≤5时查附表12
- **本例**：k=4>3，用**χ²近似法**——H近似服从自由度ν=k−1=3的χ²分布
- 查χ²界值表，P<0.05
- 拒绝H₀，接受H₁
- **结论：四组SOD活性总体分布位置不同（或不全相同）**

【考点】老师原话："H检验的推断有两种方法：第一种查表法，适用k=3且每组样本数不超过5；第二种卡方近似法，当k=3且最少样本数>5或k>3时，H近似服从自由度为k−1的卡方分布，查卡方界值表。"

## 第十部分：等级资料多组比较与两两比较（教材例11-6）

### 10.1 例题11-6：A、B、C三种方法治疗慢性喉炎

- **资料类型**：有序等级资料（无效→好转→显著→治愈）
- **设计类型**：完全随机设计（三组独立样本）
- **原医师错误**：行×列表卡方检验，丢失等级顺序信息

### 10.2 编秩与H计算

- 编秩方法与两样本等级资料相同：先各等级合计→确定秩次范围→平均秩次→各组秩和
- H=56.147，校正后Hc=63.788
- 查χ²界值表（ν=k−1=2），P<0.05
- 拒绝H₀：三种方法疗效总体分布不同

### 10.3 多组比较后的两两比较（α校正）

老师特别强调：多组比较拒绝H₀后，还需做**两两比较**判断谁与谁不同。直接重复做多次两样本秩和检验会增大Ⅰ类错误，需对α进行校正：

**情况一：所有组间两两比较**
```
α' = α / [k(k−1)/2]
```
其中k为组数，k(k−1)/2为两两比较的总次数

**情况二：一个对照组与多个实验组比较**
```
α' = α / (k−1)
```

【考点】老师原话："多组间两两比较时α要经过校正。所有组间两两比较用α除以k(k−1)/2；对照组与多个实验组比较用α除以k−1。两种校正方法不同。"

### 10.4 两两比较的检验方法

- 样本量小：精确概率法
- 样本量大：正态近似法（Z检验，同样需相持校正Z/√C）
- 将两组比较所得P值与校正后α'比较：P<α'则拒绝H₀

## 第十一部分：本课总结与方法选择决策

### 11.1 老师课堂总结要点

【考点】老师原话总结：

1. **秩和检验应用条件**：对总体分布类型、方差齐性等都不做要求——"以上都不做要求"
2. **两个独立样本比较时**：优先看是否符合t检验条件，能用t检验就用t检验，用不了才用秩和检验
3. **本课重点难点**：编秩和求秩和是否正确——课后盖住书本例题的计算部分，自己重新算一遍
4. **推断方法选择**：编完秩后判断用查表法还是正态近似法，不同资料类型有不同推断方式

### 11.2 秩和检验方法选择速查表

| 设计类型 | 资料特征 | 选用方法 | 检验统计量 | 查表/近似 |
|---------|---------|---------|-----------|----------|
| 配对设计 | 差值偏态 | Wilcoxon符号秩检验 | T+或T- | n≤50查附表10；n>50用Z |
| 单样本 | 偏态，与已知中位数比 | Wilcoxon符号秩检验 | T | 同上 |
| 两独立样本 | 偏态/方差不齐 | Mann-Whitney U检验 | 小样本组秩和T | n₁≤10或n₂−n₁≤10查附表11；大用Z |
| 两独立样本 | 等级资料 | 两样本秩和检验（等级编秩） | T | 大样本用Z/√C校正 |
| 多组独立样本 | 偏态/方差不齐 | Kruskal-Wallis H检验 | H | k=3且每组n≤5查附表12；大用χ²近似 |
| 多组独立样本 | 等级资料 | KW H检验（等级编秩） | Hc | χ²近似，需校正 |
| 多组比较后 | 需两两比较 | 校正α后两样本秩和检验 | Z | α'=α/[k(k−1)/2]或α/(k−1) |

### 11.3 关键易错点提醒

1. **配对设计不能当成组处理**——老师反复强调
2. **有序等级资料不能用卡方检验**——丢失等级顺序信息，检验效能反而下降
3. **相持超过25%必须校正**——尤其是频数表/等级资料，几乎必然需要校正
4. **成组设计取小样本组秩和为T**——因为小样本组变异程度小
5. **成组设计中0值不舍去**——与配对设计不同，0是具体观测值
6. **大样本时查ν=∞列（标准正态）**——正态近似法的本质
7. **多组H检验只能说明"不同或不全相同"**——拒绝H₀后需两两比较才能定位差异组
8. **验算公式**：T₁+T₂=N(N+1)/2，编完秩一定验算
