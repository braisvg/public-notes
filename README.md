---

## 一、项目目的

本项目将课堂录音的实时转写文本，经过**术语纠正、知识结构化、考点提取**后，整理为按课时/章节组织的学习资料，方便日常复习与考前备考。

核心工作：
- 从原始语音转写中提取知识点，纠正大量语音识别错误
- 按课时边界精准拆分，每课时独立成文件夹（含照片子目录，自包含）
- 提取老师强调的考点（保留原话），整理中英对照术语表
- 每科提供课程总览（考核方式+备考策略）和全课程知识框架思维导图
- **2026-09-10 全面升级**：11课时知识点总结大幅扩写为"考试版"（每文件6500-14000字），插入课堂PPT照片，结合教材PDF补充老师未讲透的内容
- **2026-09-11 迁移Obsidian**：全部资料迁入Obsidian库（`E:\GitHub\medisidian`），通过Git同步到GitHub，照片移入各课时文件夹内部
- **2026-09-14 新增3课时**：生理学第4课（动作电位机制与肌细胞收缩，73张照片按时间戳插入+批注）、毛概第2课（毛泽东思想及其历史地位）、医学伦理学第3课（医疗纠纷处理与医患沟通技巧，22张照片全插入+批注）；**照片按时间戳匹配知识点**、**优先放拍全的照片（重要过程没拍全也放）**、**每张插图附📝文字批注**——方法论详见 `AGENTS.md` 第2.4节

## 五、Obsidian 与 GitHub 同步

本项目同时是一个 **Obsidian 库**，通过 Git 同步到 GitHub 远程仓库（`github.com/braisvg/medisidian`）。

### 同步方式
- **Obsidian Git 插件**：检测到文件变更后，停止编写1分钟自动执行 `git commit`（提交信息格式 `vault backup: 时间戳`）
- **手动 push**：Obsidian Git 插件默认只自动 commit 不自动 push，需在 Obsidian 左侧栏点 Git 插件的 push 按钮，或用 GitHub Desktop 推送
- **启动时 pull**：打开 Obsidian 时自动从远程 pull 最新内容

### 图片语法
- 使用**标准Markdown图片语法**：`![说明文字](./照片/图片名.jpg)`
- 照片存放在对应课时文件夹内的 `照片/` 子目录，引用路径简洁
- **不使用** Obsidian wikilink（`![[图片名.jpg]]`），确保 GitHub 网页也能正常渲染图片

### 注意事项
- `.obsidian/workspace.json` 和 `.obsidian/workspace-mobile.json` 已加入 `.gitignore`（本地窗口布局不同步）
- `.trash/`（Obsidian回收站）、`*.tmp`、`.DS_Store` 等临时文件已忽略
- AI 操作完成后执行 `git add -A && git commit`，Obsidian 插件或用户手动 push 到 GitHub

## 六、如何追加新课时

当有新的课堂录音转写需要整理时：

1. **备份转写**：将新的 `.md` 转写文件放入 `原始转写备份/`，命名格式 `课程内容描述_实时转写.md`
2. **判断科目与课时**：阅读转写内容，确定属于哪个科目、是第几课
3. **创建文件夹**：在对应科目下创建 `第N课_课时标题/` 文件夹，内含 `照片/` 子目录
4. **分类照片（按时间戳匹配）**：照片文件名自带时间戳——手机相机为 `IMG年月日时分秒.jpg`（如 `IMG20260910143025.jpg` = 2026年9月10日14:30:25），截图为 `Screenshot_年月日-时分秒-xxx.jpg`。先确定课程时间范围（从课表或转写推断），再按时间戳筛选出本课照片，按拍摄时间排序后放入 `第N课_课时标题/照片/` 目录，重命名为 `序号_语义化中文名.jpg`
5. **提取知识点**：从转写中提取知识点，参考 `_术语纠正对照表.md` 纠正术语，写入 `知识点总结.md`
6. **按时间轴插入照片**：将课程时间轴与知识点章节顺序对应（如前20分钟→导入，中间→各知识点，末尾→总结），根据每张照片的拍摄时间判断它对应哪个知识点，插入到该知识点段落旁边并配简短说明。引用格式 `./照片/文件名.jpg`。详细方法论见 `AGENTS.md` 第2.4节
7. **整理考点术语**：提取老师强调的考点（保留原话），制作中英对照术语表，写入 `考点与术语.md`
8. **更新总览**：在该科 `00_课程总览与备考指南.md` 的课时索引中新增条目
9. **更新思维导图**：在 `知识框架与思维导图.md` 中加入新课时内容
10. **Git提交**：`git add -A && git commit -m "新增：XX科目第N课（课时标题）学习资料"`

> 详细SOP见 `AGENTS.md` 第4节。

## 八、术语纠正说明

原始转写来自语音识别，存在大量错误。本项目所有学习资料均已根据专业知识和上下文进行纠正。常见错误类型：

### 生物化学类
- 碱基名称：向嘌呤→腺嘌呤(A)、鸟飘零→鸟嘌呤(G)、包密定→胞嘧啶(C)、生效密定→胸腺嘧啶(T)、量密定→尿嘧啶(U)
- 糖类：木糖→核糖、脱跟核糖→脱氧核糖
- 化学键：芯片→肽键、共沉淀→共价键、电离子键→离子键、化中含力→范德华力
- 其他：软病毒→朊病毒、赫兰酸和浪酸→色氨酸和酪氨酸、沃森斯雷克→沃森和克里克

### 实验操作类
- 乌拉坎→乌拉坦（麻醉剂）、耳源静脉→耳缘静脉、竞争→进针、动漫家→动脉夹、组织茧→组织剪、眼科茧→眼科剪

### 生理学类
- 异化扩散→易化扩散、原发性子宫→原发性主动转运、包内/包外→胞内/胞外

### 通用平台类
- 操作/操心→超星（学习平台）、高新群→班级群、分流同化→分离纯化

### 卫生统计学类
- 好菌素/菌数→均数、几个菌素→几何均数、正变态/正电态/正偏爱→正偏态、横卡→零、阻断/主干→组段、抑制性→异质性、可移值→可疑值、国债/盈率→累计频率

> 完整对照表见 `_术语纠正对照表.md`。如发现新的常见错误，欢迎补充。
